# Audit record — ForgePlan vNext pack

Полные отчёты адверсариального аудита пакета (2026-08-01). Сводка и связи в графе:
`EVID-149`, `PROB-082`, `PROB-083`, якорь программы — `EPIC-009`.

Материал лежит здесь, а не во временном каталоге, потому что первая попытка его сохранить
именно так и потерялась: отчёты писались в `/private/tmp/.../scratchpad`, который был
очищен через сутки. Восстановлено из журналов workflow.

## Как это делалось

25 агентов в изолированных контекстах, только чтение. Первый прогон — 4 ревьюера материала
(architecture / issues / protocol / governance) + 5 ревьюеров реальности (коллизии с 18 ADR,
дубли с 65 PRD, верификация фактических утверждений против кода, пересечение с открытыми
GitHub issue, стресс-тест продуктовой границы) + размещение + инвентарь потерь + синтез +
критик синтеза. Второй прогон — 7 кандидатов в баги, каждый затем атакован независимым
скептиком с установкой «по умолчанию опровергнут».

## Читать с поправкой

Критик и последующая проверка опровергли часть выводов самого брифа. Существенное:

- Бриф рекомендовал `git checkout <ветка> -- CLAUDE.md` для переноса правок. Команда
  **уничтожила бы** их: правки существовали только в рабочем дереве. Не выполнялась.
- Утверждение «ADR-016/017 не резолвятся» — ошибка оператора: запускался `scan-import`
  вместо `reindex`. Причина ошибки — документация, заведена как #420.
- Бриф считал граф по корпусу, из которого выпал 21 артефакт. После `forgeplan reindex`
  числа другие.

Раздел 6 критики («Что не посмотрел никто») содержит наиболее ценное — в том числе то,
что бриф пропустил, и то, что опрокидывает часть его собственных чисел.
