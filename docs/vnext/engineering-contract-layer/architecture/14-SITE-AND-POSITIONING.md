# Site and Product Positioning

## Hero

**From engineering intent to verified change**

ForgePlan turns requirements, decisions, constraints and acceptance criteria into versioned work contracts for AI coding agents — then verifies the evidence behind every completed change.

**Give every agent a contract. Require proof.**

## Основной цикл

```text
DEFINE → CONTRACT → EXECUTE ANYWHERE → VERIFY → ACCEPT
```

ForgePlan не должен говорить, что сам выполняет `Build`, если работу выполняет внешний агент.

## Три сценария

### One agent

ForgePlan + Cursor / Codex / OpenCode / Claude Code.

### Multi-agent

ForgePlan + Kandev / Vibe Kanban / Conductor.

### Autonomous engineering

ForgePlan + Paperclip.

## Product family

- ForgePlan Core — contracts, policy, Evidence, lifecycle;
- ForgePlan Web — read-only observability;
- ForgePlan Extensions — integrations and methodology packs;
- ForgePlan Protocol — schemas and semantics.
