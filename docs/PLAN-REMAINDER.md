## Что закрыто в этой ветке

- `resolve_id`: одинаковые номера в разных проектах больше не «первый
  совпавший» — неоднозначность возвращается типизированным отказом.
- `claim` по ключу уходил как алиас; CLI перекрывал id на display id.
- Дедлок `phase`/`phase-advance`: миграция брала замок повторно.
- MCP-адаптер различает типизированный отказ; `dispatch` сравнивает
  претензии по ключу, блокировки — по номеру.
- `import` публикует документы под их ключами; повторный импорт не создаёт
  дубликаты.
- `update`, `validate`, `new`, `memory`, `clippy`-семейства — приведены
  к контракту «отказ, а не молчаливая запись».
