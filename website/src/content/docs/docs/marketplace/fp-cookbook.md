Practical cookbook of forgeplan CLI recipes - task-oriented guides covering onboarding, PRD authoring, evidence patterns, workflow cycles, multi-plugin discipline, AI-pair dispatch, troubleshooting and a CLI/MCP quick reference, each shaped as goal -> command -> example -> common errors. Use when you know what you want from forgeplan and need the exact invocation, not the methodology behind it. Full history in CHANGELOG.md.

**Cost**: light | **Stability**: stable | **Version**: 1.2.4 | **Category**: developer-tools

**Targets**: claude-code

**Requires**: Nothing beyond Claude Code

## Skills

- `fp-cookbook` - Practical cookbook of forgeplan CLI recipes - 25+ task-oriented how-to guides answering "how do I do X?" for forgeplan CLI users and Claude as an assistant.
