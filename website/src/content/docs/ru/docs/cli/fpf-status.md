`forgeplan fpf status` отображает состояние локальной базы знаний **First Principles Framework**: откуда она была загружена, сколько секций находится в LanceDB, когда последний раз выполнялась индексация и является ли она устаревшей относительно поставляемой спецификации.

Думайте об этом как о `forgeplan health` специально для базы знаний FPF.

## Когда использовать

- **Сразу после `fpf ingest`** - проверить, что загружено ожидаемое количество секций.
- **Когда `fpf search` возвращает ноль результатов** - убедиться, что база знаний действительно заполнена.
- **После обновления Forgeplan** - проверить, нужна ли повторная индексация.
- **При свежем клонировании** - поскольку `.forgeplan/lance/` находится в gitignore, новые чекауты начинаются с пустой базы знаний.
- **В smoke-тестах CI** - убедиться, что база знаний готова перед запуском потоков рассуждений.

## Когда НЕ использовать

- Для проверки здоровья проекта на уровне артефактов - используйте [`forgeplan health`](/ru/docs/cli/health/).
- Для полного списка секций - используйте [`fpf list`](/ru/docs/cli/fpf-list/).

## Использование

```text
forgeplan fpf status
```

## Опции

```text
  -h, --help     Показать справку
  -V, --version  Показать версию
```

## Примеры

```bash
# Проверить статус базы знаний
forgeplan fpf status

# Типичный сценарий "пустого рабочего пространства"
forgeplan init -y
forgeplan fpf status       # → не проиндексировано
forgeplan fpf ingest
forgeplan fpf status       # → проиндексировано, N секций
```

## Что вы увидите

Типичные отображаемые поля:

- **Source** - путь / версия спецификации FPF, которая была проиндексирована.
- **Ingested sections** - количество строк в таблице LanceDB `fpf_kb`.
- **Last ingest** - временная метка (или "never").
- **Staleness** - является ли поставляемая спецификация более новой, чем проиндексированные данные.
- **Semantic search** - включена ли функция `semantic-search` и присутствуют ли эмбеддинги.

## Как это вписывается

`fpf status` - это **гейт-команда**: она отвечает на вопрос да/нет "можно ли сейчас использовать мою базу знаний FPF?" перед запуском `fpf search`, `fpf check` или `forgeplan reason --fpf`.

```
fpf ingest  →  fpf status (проверка)  →  fpf search / reason --fpf
```
