## Снимок CLI help

Источник: `forgeplan 0.39.0+constellation.s1.1`, `forgeplan playbook show --help`.

```text
Show playbook structure (steps, delegations, requires)

Usage: forgeplan playbook show [OPTIONS] <TARGET>

Arguments:
  <TARGET>  Playbook name (e.g. brownfield-code) or path to .yaml file

Options:
      --json     Output as JSON
  -h, --help     Print help
  -V, --version  Print version
```
