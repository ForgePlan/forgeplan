title: forgeplan import
description: "Восстановление артефактов из JSON-файла экспорта - повторная инициализация, резервное копирование и миграция рабочего пространства"
---

`forgeplan import` читает JSON-пакет `forgeplan export`, записывает канонические Markdown-артефакты и объявленные связи, затем обновляет производный индекс. Это не побайтовое восстановление workspace: команда не возвращает всю историю оценок, config, receipts и состояние сессий. Сохраняйте полную резервную копию workspace вместе с JSON.

## Когда использовать

- Восстановление поддержанных полей артефактов и связей в отдельный workspace с сохранением оригинала.
- Передача пакета между машинами после проверки совместимости версий.
- Изучение экспорта до миграции без удаления существующего workspace.
- Клонирование состояния рабочего пространства коллеги для отладки или воспроизведения ошибки.

## Когда НЕ использовать

- Для слепого слияния с живым workspace — существующие ID без `--force` пропускаются; force заменяет их и может уничтожить текущее содержимое.
- Для индекса канонического Markdown — используйте `forgeplan index` для Constellation или соответствующий legacy `forgeplan reindex`, не `scan-import`.
- Для импорта данных из другого инструмента - JSON-схема Forgeplan является внутренней. Поддерживаются только файлы, созданные `forgeplan export`.

## Использование

```text
forgeplan import [OPTIONS] <PATH>
```

## Аргументы

```text
  <PATH>  Путь к JSON-файлу экспорта
```

## Опции

```text
      --force    Перезаписать существующие артефакты
  -h, --help     Вывести справку
  -V, --version  Вывести версию
```

## Примеры

### Пример 1: Восстановление после повторной инициализации

```bash
forgeplan export --output backup.json
cp -r .forgeplan .forgeplan-backup-$(date +%Y%m%d)
mkdir recovery-workspace
cd recovery-workspace
forgeplan init -y
forgeplan import ../backup.json
forgeplan health
```

Это изолированная проверка восстановления, не гарантия полного аварийного восстановления. До использования результата сравните тела и связи с сохранённой копией workspace.

### Пример 2: Принудительная перезапись при конфликте

```bash
forgeplan import backup.json --force
```

Без `--force` существующие ID пропускаются. Активные заглушки могут понижаться до draft; force обходит эту защиту. Связи могут примениться частично — изучайте сводку и предупреждения. Перед force сравните копию с текущим каноническим содержимым.

### Пример 3: Передача рабочего пространства между машинами

```bash
# на машине A
forgeplan export --output workspace.json
scp workspace.json machine-b:/tmp/

# на машине B
forgeplan init -y
forgeplan import /tmp/workspace.json
forgeplan list
```

Подходит для переноса поддержанных полей и объявленных связей, но не всей истории оценок, устаревания и состояния workspace.

## Как это вписывается в рабочий процесс

`import` - это инструмент восстановления/миграции, а не часть ежедневного цикла Shape → Validate → Code → Evidence → Activate. Он тесно связан с `export`:

1. До разрушительных действий сохраните экспорт и полную копию workspace.
2. Импортируйте для проверки в отдельный инициализированный workspace.
3. Сравните тела, статусы, числа и связи; одного `health` недостаточно для доказательства эквивалентности.

Для обслуживания Constellation используйте `forgeplan index`.
`scan-import` обнаруживает внешние документы, не восстанавливает существующие канонические файлы.

## Примечания по безопасности

- **После импорта запустите `forgeplan health`.** Сравните поддержанные поля артефактов и связи с сохранённой копией. Новые оценки могут отличаться: JSON-пакет не восстанавливает историю скоринга.
- **`--force` является деструктивным.** Он заменяет существующее каноническое содержимое. Если сомневаетесь, изучите импорт в отдельном инициализированном workspace.
- **Формат зависит от версии.** Проверяйте совместимость изолированно; `migrate` не обещает преобразование любого старого экспорта.
- **Не правьте JSON необдуманно.** Некорректные поля или связи меняют результат; гарантии проверки checksum экспорта здесь нет.
- **`import` записывает Markdown.** Force может удалить и пересоздать конфликтующий артефакт. На Constellation публикация идёт после записи файлов; проверяйте диагностику reconciliation.
