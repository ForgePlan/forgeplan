---
title: forgeplan progress
description: "Трекер прогресса для артефактов на основе чекбоксов"
---

Анализирует списки чекбоксов (`- [ ]` / `- [x]`) внутри тел артефактов и сообщает, сколько выполнено. По соглашению, каждое функциональное требование (FR) или фаза реализации в PRD/RFC записывается как чекбокс, и `progress` отвечает на вопрос «насколько реализован этот PRD?»

## Когда использовать

-   Ежедневные стендапы - быстрый процент выполнения для каждого PRD
-   Подготовка к релизу - какие PRD ещё не выполнены на 100%
-   Отчётность - передача JSON в дашборды

## Когда не использовать

-   Вам нужно _качество_ артефакта (а не завершённость) → используйте [`forgeplan score`](/ru/docs/cli/score/)
-   Вам нужен сводный показатель _здоровья_ → используйте [`forgeplan health`](/ru/docs/cli/health/)

## Использование

```text
forgeplan progress [OPTIONS] [ID]
```

## Аргументы

```text
  [ID]  Artifact ID (shows all if omitted)
```

## Опции

```text
      --json     Output as JSON for machine consumption
  -h, --help     Print help
  -V, --version  Print version
```

## Примеры

Все артефакты, таблица по умолчанию:

```bash
forgeplan progress
```

Только один PRD:

```bash
forgeplan progress PRD-001
```

Машиночитаемый формат для дашборда:

```bash
forgeplan progress --json | jq '.progress[] | {id, percent}'
```

## Интерпретация вывода

Текстовый вид группирует артефакты по типам: Unicode-индикатор из 24 ячеек,
completed/total, округлённый целый процент и `WIP` или `DONE`, затем общие суммы.
ID выбирает подробный вид со строками чекбоксов.

`--json` содержит `progress` и `_next_action`; запись имеет `id`, `title`,
`kind`, `completed`, `total`, `percent`. И текст, и JSON исключают артефакты
без чекбоксов; отдельный JSON-запрос к такому артефакту вернёт `progress: []`.

Распознаются строки `- [ ] ` / `* [ ] ` и отмеченные варианты `x`/`X`
после ведущих пробелов. Парсер построчно читает сохранённое тело, включая
похожие на чекбоксы примеры в блоках кода. Код и завершённость реализации
не проверяются. При 100% подсказка может предлагать `activate`, но гейты
активации остаются в силе.

## Как это вписывается

`progress` отслеживает _выполнение_. Его родственный инструмент [`forgeplan score`](/ru/docs/cli/score/) отслеживает _качество_ (R_eff + F-G-R). Здоровый PRD выполнен на 100% и имеет R_eff > 0.

```
progress  →  "are we done building?"
score     →  "do we trust it?"
health    →  aggregate both
```
