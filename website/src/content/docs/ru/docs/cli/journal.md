Показывает артефакты решений по `created_at`, от новых к старым, с текущим числом связанных доказательств и плоским вспомогательным расчётом R_eff. Без фильтра типа включает ADR, Note, PRD, RFC, Epic, Spec, Problem и Solution. Это не поток активаций, продлений, замещений или отмен; для истории изменений используйте [`log`](/ru/docs/cli/log/).

## Когда использовать

- Онбординг - "как мы сюда пришли?"
- Ретроспективы - какие решения хорошо себя показали, а какие были замещены
- Режим `--risk`: артефакты без связанных доказательств, с R_eff ниже 0.3 или просроченными учитываемыми доказательствами.
- Обзор недавно созданных решений перед ретроспективой.

## Когда не использовать

- Вам нужны низкоуровневые CRUD-события → используйте [`forgeplan log`](/ru/docs/cli/log/)
- Вам нужен текущий снимок → используйте [`forgeplan health`](/ru/docs/cli/health/)

## Использование

```text
forgeplan journal [OPTIONS]
```

## Опции

```text
  -t, --type <TYPE>  Filter by kind (adr, note, problem, solution)
      --risk         Show only at-risk decisions (no evidence, stale, low R_eff)
  -h, --help         Print help
  -V, --version      Print version
```

## Примеры

Полная временная шкала решений:

```bash
forgeplan journal
```

Только ADR - архитектурная запись, меньший набор:

```bash
forgeplan journal --type adr
```

Режим риска — не только для активных артефактов:

```bash
forgeplan journal --risk
```

## Интерпретация вывода

Для записи печатает дату создания, ID, тип и заголовок. При наличии доказательств вторая строка содержит `R_eff: … | … evidence` и маркер риска. Колонки события и стрелки к заменяющему артефакту нет.

`--risk` оставляет запись, если число доказательств равно нулю, плоский R_eff `< 0.3` или учитываемое доказательство просрочено. Статус жизненного цикла не фильтруется. Терминальные доказательства входят в число связанных пакетов, но исключаются из минимума и признака просрочки. Поэтому нулевой балл не доказывает отсутствие связей.

Этот плоский расчёт отличается от рекурсивного, учитывающего зависимости `forgeplan score`. Команда печатает только текст; опции `--json` нет.

## Как это работает

`journal` находится между `log` (сырые изменения) и `health` (текущий свод):

```
log         → journal    → health
everything    decisions    current state
```

Используйте его, чтобы рассказать историю решений; используйте `health`, чтобы увидеть, где вы находитесь сейчас.
