---
title: forgeplan untag
description: "Удалить теги из артефакта"
---

Удаляет один или несколько тегов из артефакта. Обратная операция для
[`forgeplan tag`](/ru/docs/cli/tag/). Используйте это для удаления меток, которые уже не нужны (`legacy`,
когда метка перестала быть устаревшей, `wip` для того, что уже выпущено) или для исправления ошибок,
возникших в результате массового тегирования.

## Использование

```text
forgeplan untag <ID> <TAGS>...
```

## Аргументы

```text
  <ID>       Artifact ID
  <TAGS>...  Tags to remove
```

## Опции

```text
  -h, --help     Print help
  -V, --version  Print version
```

## Как это работает

1. Загружает запись по точному ID и синхронизирует имеющиеся правки проекции.
2. Удаляет теги по **точному равенству строк**. В отличие от `tag`, не обрезает и не приводит входные значения к нижнему регистру.
3. Обновляет индекс и формирует Markdown-проекцию.

Используйте сохранённое написание (`legacy`, не `Legacy`) и точный ID из `list`. Неизвестные теги игнорируются. Текст “Removed” сообщает число переданных аргументов, а не реально удалённых тегов; итог проверяйте по `Current tags`. Режима JSON нет.

## Примеры

Удалить один тег:

```bash
forgeplan untag PRD-001 legacy
```

Удалить несколько тегов за один вызов:

```bash
forgeplan untag PRD-018 wip experimental source=draft
```

Исправить ошибку массового тегирования (сначала тегировать, затем сразу удалить тег):

```bash
forgeplan tag PRD-001 securiti   # typo
forgeplan untag PRD-001 securiti
forgeplan tag PRD-001 security   # correct
```

## Массовая очистка

Чтобы удалить тег из каждого артефакта (например, при выводе таксономии из употребления), используйте в сочетании с
`list --tag`:

```bash
forgeplan list --tag wip --json | jq -r '.[].id' | \
  xargs -I {} forgeplan untag {} wip
```

`reindex` импортирует теги из проекции при создании отсутствующей записи, но при инкрементальной синхронизации существующей записи обновляет тело, не столбец тегов. Он не исправляет метаданные тегов существующих записей и не нормализует все теги воркспейса на месте. Исправляйте их через `untag` / `tag`; для старых меток с разным регистром удалите точное сохранённое написание перед добавлением канонического значения.

## Примечания

- `forgeplan untag PRD-001 Legacy` не удалит сохранённый `legacy`; передавайте точное значение в нижнем регистре.
- Если вы хотите переместить артефакт из одного тега в другой, выполните `untag`, а затем
  `tag` - вспомогательной команды `retag` нет.
- Удаление source-tier тега не меняет CL оценки в 0.38.0: CL берётся из полей тела доказательства. Связи не изменяются.
