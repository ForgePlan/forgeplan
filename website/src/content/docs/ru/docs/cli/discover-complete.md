`forgeplan discover complete <SESSION_ID>` закрывает сессию brownfield-обнаружения. Команда помечает строку сессии как завершённую, запускает проход рекомендаций по всем накопленным находкам и выводит список **предложенных артефактов** - обычно Problem-карт, PRD, Note, а иногда и ADR - для создания пользователем через `forgeplan new`.

Здесь brownfield-конвейер превращает сырые находки в реальное состояние методологии.

## Когда использовать

- **После того как агент завершил обход исходных уровней** и `discover show` сообщает о достаточном покрытии.
- **В конце онбординг-спринта** - кристаллизовать всё изученное в артефакты.
- **Когда нужно остановить сессию и зафиксировать всё найденное на данный момент** - частичные сессии всё равно производят рекомендации.

## Когда НЕ использовать

- Пока агент всё ещё активно отправляет находки - дождитесь стабилизации.
- Для отмены без сохранения - отката нет; после завершения предложения выдаются.
- На уже завершённой сессии - идемпотентно, но бессмысленно.

## Использование

```text
forgeplan discover complete <SESSION_ID>
```

## Аргументы

```text
  <SESSION_ID>   Идентификатор сессии обнаружения (из discover list / start)
```

## Опции

```text
  -h, --help     Вывести справку
  -V, --version  Вывести версию
```

## Примеры

```bash
forgeplan discover complete disc-001

# Полный цикл онбординга
forgeplan init -y
forgeplan discover start
# ... агент работает ...
forgeplan discover show disc-001
forgeplan discover complete disc-001
# → предложения выведены; создайте те, что принимаете
forgeplan new prob "Auth drift between docs and code"
forgeplan new prd  "Unified config loader"
```

## Что делает проход рекомендаций

При завершении движок:

1. **Группирует находки** по категориям (решения, инварианты, дрифт, долг, риски, владение).
2. **Дедуплицирует** - объединяет находки, ссылающиеся на один и тот же модуль/концепт.
3. **Сопоставляет категории с типами артефактов** - дрифт → Problem, крупные решения → ADR, пробелы → PRD, наблюдения → Note.
4. **Предлагает глубину** - Tactical / Standard / Deep на основе эвристик радиуса поражения и обратимости.
5. **Выдаёт предложения** в виде списка команд `forgeplan new`, которые пользователь может принять, отредактировать или пропустить.

Пользователь сохраняет контроль: предложения выводятся, но не создаются автоматически.

## Как это вписывается

`discover complete` - это **точка передачи** от обнаружения к нормальному жизненному циклу Forgeplan:

```
discover start → (находки) → discover complete → предложения
                                                    ↓
                          forgeplan new prob/prd/adr/note ...
                                                    ↓
                          validate → reason → activate
```

Отсюда проект течёт через стандартный цикл Shape → Validate → ADI → Code → Evidence → Activate, как любая greenfield-работа.
