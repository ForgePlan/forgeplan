## Снимок CLI help

Источник: `forgeplan 0.39.0+constellation.s1.1`, `forgeplan plugins info --help`.

```text
Show details for a specific plugin (path, version, description)

Usage: forgeplan plugins info [OPTIONS] <NAME>

Arguments:
  <NAME>  Plugin name (e.g. c4-architecture)

Options:
      --json     Output as JSON
  -h, --help     Print help
  -V, --version  Print version
```
