description: "Показывает напрямую связанные просроченные доказательства и сравнивает плоские оценки с просрочкой и без неё. Это не прогноз и не рекурсивная оценка с зависимостями."
---

Показывает артефакты, кроме самих evidence, с напрямую связанными нетерминальными доказательствами с истёкшим сроком. Сравнивает плоскую оценку вспомогательного расчёта с просрочкой и без неё; это не рекурсивный результат `score`, учитывающий зависимости, и не прогноз. Снижение может быть нулевым, если другой пакет уже задаёт тот же минимум.

## Использование

```text
forgeplan decay
```

## Опции

```text
  -h, --help     Print help
  -V, --version  Print version
```

## Как читать отчёт

Выводит оценку без просрочки, текущую оценку, их абсолютную разность и ID просроченных доказательств с датой истечения, числом прошедших дней и индивидуальной оценкой. Просроченное доказательство даёт вклад 0.1. Пакеты со статусом `superseded` или `deprecated` исключены из минимума.

## Пример

```bash
forgeplan decay
forgeplan stale
forgeplan score PRD-001 --json
```

## Что делать с просрочкой

Перед продлением изучите доказательства. При необходимости повторите измерения или тесты, создайте и свяжите замену, примените `supersede` к прежним пакетам. Продлевайте только после реального пересмотра. `stale` перечисляет истёкшие сроки, `decay` показывает влияние связанных доказательств.
