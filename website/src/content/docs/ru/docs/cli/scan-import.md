Импортирует внешние Markdown-документы в артефакты Forgeplan при подключении существующего проекта. Это не команда восстановления индекса: обычный обход проекта исключает `.forgeplan/`, а содержимое существующих артефактов пропускается, не обновляется. Для клонированного репозитория и правок markdown пространства используйте `reindex`.

## Использование

```text
forgeplan scan-import [OPTIONS]
```

## Опции

```text
      --path <PATH>  Directory to scan (default: standard doc dirs)
      --dry-run      Preview only, don't actually import
  -h, --help         Print help
  -V, --version      Print version
```

## Обнаружение и предварительный просмотр

По умолчанию читаются стандартные каталоги документации и выбранные Markdown-файлы корня, не все каталоги репозитория. `--path` меняет корень сканирования и должен разрешаться внутри проекта; правила стандартных каталогов и файлов корня сохраняются. Символические ссылки, слишком большие файлы и исключённые каталоги пропускаются. Тип определяется по frontmatter, имени или содержимому; нераспознанные файлы отмечаются unknown, а не обязательно становятся Notes.

## Примеры

```bash
# In a workspace initialized for an existing project:
forgeplan scan-import --dry-run
forgeplan scan-import --path docs/architecture --dry-run
# Review the detected sources before a real import:
forgeplan scan-import --path docs/architecture
forgeplan list
forgeplan health
# Different task: refresh tracked .forgeplan Markdown after a clone/edit:
forgeplan reindex
```

## Существующие артефакты и файлы

Реальный импорт создаёт Markdown в пространстве и запись LanceDB, сохраняя поддерживаемый frontmatter источника, например автора, теги и связи. Если ID уже существует, запись отмечается skipped, её содержимое не обновляется. Повторный запуск может восстановить отсутствующий markdown; это исключение, не общий режим обновления. Поэтому повторный импорт не синхронизирует ручные правки тела. `init --scan` запускает этот импорт после инициализации.

## Ограничения dry-run и успешного выхода

`--dry-run` показывает найденные записи без записи импортируемых артефактов и возвращается до проверки существующего ID. Его счётчики не гарантируют, что все записи будут импортированы. Изучите реальные imported/skipped/unknown/failed и предупреждения: ошибки отдельных файлов могут сообщаться без ненулевого кода процесса. Импорт не доказывает полноту или качество доказательств. Валидируйте выбранные артефакты и изучите health.

## Восстановление через reindex

Для уже отслеживаемого markdown `.forgeplan/` выполните `forgeplan reindex`; не удаляйте индекс перед scan-import. Ни сканирование, ни пара экспорта и импорта не восстанавливают полную историю изменений. `import` предназначен для поддерживаемого пакета экспорта; конфигурацию и локальные данные сохраняйте отдельно.
