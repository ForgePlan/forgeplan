Предлагает глубину проработки и цепочку артефактов до начала работы. Это рекомендация, не доказательство реализации, не разрешение пропустить проверки и не автоматическое создание артефактов.

## Использование

```text
forgeplan route [OPTIONS] <DESCRIPTION>
```

## Аргументы

```text
  <DESCRIPTION>  Task description in natural language
```

## Опции

```text
      --explain        Optional: use LLM to explain the routing decision (deprecated, use --level 1)
      --level <LEVEL>  Routing level: 0 = keywords (default), 1 = LLM-classified
  -h, --help           Print help
  -V, --version        Print version
```

## Уровни маршрутизации

Режим по умолчанию автоматический, хотя справка 0.38.0 называет Level 0 значением по умолчанию. `--level 0` принудительно включает правила по словам. Автоматический режим пробует настроенный LLM, при недоступности возвращается к правилам; результат Deep может вызвать Level 2. `--level 1` запрашивает классификацию LLM; runtime принимает и `--level 2` для классификации с рассуждением. `--explain` — устаревший вариант Level 1.

Даже явный Level 1 или 2 может вернуться к словам при отсутствии конфигурации, учётных данных, ошибке провайдера или неразбираемом ответе. Рассуждение Level 2 выполняется лишь после классификации Deep/Critical. Keyless-провайдерам Ollama и `claude-code` ключ не нужен, но нужны runtime или авторизация CLI. Для режима без LLM используйте `--level 0` **без** `--explain`: вместе они могут вызвать прежний путь LLM-пояснения. Вывод только текстовый; JSON-опции нет.

## Примеры

```bash
forgeplan route --level 0 "add rate limiting to API"
forgeplan route --level 1 "refactor the embedding pipeline"
forgeplan route "fix typo in README"
```

## Результат и дальнейшие действия

Сопоставьте глубину, цепочку, уверенность, обоснование и альтернативы с объёмом и обратимостью изменения. При низкой уверенности уточните описание или проведите разбор. LLM расходует сервис или тариф; для режима без LLM явно передайте Level 0. Маршрутизация может обновить сессию, но артефакты создаются явно через `new`. Для существующего используйте `calibrate`. Не рассчитывайте на обучение при активации или эскалацию CLI по порогу исторической уверенности.

При наличии воркспейса обработчик пытается сохранить `route_depth`, фазу сессии `routing` и её время; ошибки сохранения игнорируются. Маршрутизация по словам работает без воркспейса. Пустое описание отклоняется.
