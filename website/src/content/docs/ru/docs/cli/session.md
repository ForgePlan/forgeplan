Показывает текущую методологическую сессию; `--reset` сбрасывает её. Состояние сессии отдельно от рекомендательного этапа артефакта, который показывают `phase` и `phase-advance`.

## Использование

```text
forgeplan session [OPTIONS]
```

## Опции

```text
      --reset    Reset session to Idle
  -h, --help     Print help
  -V, --version  Print version
```

## Фазы и вывод

Фазы сессии: `idle`, `routing`, `shaping`, `coding`, `evidence`, `pr`. Вывод содержит фазу, артефакт и глубину с состоянием ограничений при наличии, метку начала `Since` при наличии и до пяти последних переходов. Длительность не вычисляется. Этапы артефакта `validate`, `adi`, `test`, `audit`, `done` не являются фазами сессии.

## Примеры

```bash
forgeplan session
forgeplan session --reset
```

## Сброс и границы действия

Сброс ставит фазу Idle и очищает активный артефакт, глубину маршрута и время начала фазы. История переходов сессии сохраняется; артефакты и их рекомендательная история этапов не меняются. Перед сбросом изучите активную работу. Историю артефакта смотрите через `phase ID`, состояние пространства — через `health`.
