Экспортирует записи артефактов и типизированные связи в JSON-пакет версии 1. Он включает содержимое, метаданные, теги, кешированный R_eff, сроки действия и концы связей. Это не полная копия пространства и не история изменений.

## Использование

```text
forgeplan export [OPTIONS]
```

## Опции

```text
  -o, --output <OUTPUT>  Output file path (default: .forgeplan/export.json)
  -h, --help             Print help
  -V, --version          Print version
```

## Forgeplan 0.38.0

Пакет содержит r_eff_score и created_at/updated_at, но import 0.38.0 не восстанавливает эти сохранённые значения: оценки пересчитываются отдельно, временные метки назначаются заново. Это переносимый пакет артефактов и связей, не точный снимок всей базы или истории.

## Что не входит в экспорт

Конфигурация, значения переменных с ключами API, кеши моделей, claims, квитанции корзины, состояние сессии и другие файлы не включаются. При необходимости сохраните защищённую файловую копию. Экспорт не гарантирует воспроизведение всех настроек провайдера или показателей health на другой машине.

## Примеры

```bash
forgeplan export --output ../forgeplan-backup.json
cp -R .forgeplan ../forgeplan-workspace-backup
# In a separately initialized destination workspace:
forgeplan import ../forgeplan-backup.json
forgeplan health
```

## Копирование и передача

По умолчанию файл — `.forgeplan/export.json`; перед заменой файлов пространства задайте внешний путь. Экспорт не зашифрован и может содержать закрытые сведения. Просмотрите его перед передачей; не публикуйте пакет автоматически. Для клонированного репозитория с markdown используйте `reindex`, а не экспорт и импорт.
