Создаёт векторы семантического поиска для артефактов с изменившимися заголовком или содержимым. Команда сравнивает хеши и пропускает актуальные векторы. Если обновлять нечего, модель не загружается.

## Использование

```text
forgeplan embed
```

## Опции

```text
  -h, --help     Print help
  -V, --version  Print version
```

## Релизные сборки и кеш

Релизные сборки Forgeplan 0.38.0 включают семантический поиск. Веса BGE-M3 загружаются отдельно при первом использовании и занимают около 2.1 GB. Движок tract работает на CPU, а не CUDA или Metal. Сборка без `semantic-search` отклоняет команду, а не завершается успешной пустой операцией.

## Что делает команда

Команда вычисляет вектор по заголовку и первым `embedding.chunk_size` символам тела (по умолчанию 2000), затем обновляет один вектор и хеш на артефакт в LanceDB. Тело обрезается для предпросмотра, а не разбивается на несколько поисковых фрагментов. Размерность BGE-M3 — 1024. Отдельную базу знаний FPF эта команда не заполняет.

## Расположение кеша

Кеш общий для проектов: `~/Library/Caches/forgeplan/models` на macOS, `~/.cache/forgeplan/models` на Linux и системный каталог кеша на Windows. `FORGEPLAN_MODEL_CACHE` переопределяет расположение. Проектный `.fastembed_cache/` — прежний вариант, а не текущий путь по умолчанию.

## Пример

```bash
# Optional: download the model before the first search.
forgeplan setup --skip-alias --skip-hooks
forgeplan embed
forgeplan search "trust calculus" --semantic
```

## Когда достаточно поиска по словам

BM25 не требует векторов. Используйте поиск по словам, если загрузка модели, сеть или вычисления нежелательны. Отсутствующая или повреждённая модель может помешать семантическому поиску; не считайте неудачное вычисление векторов успешным.

Ошибки кодирования отдельных артефактов печатаются как `FAIL` и учитываются в итоговом счётчике, но цикл возвращает успех. Проверяйте число ошибок и stderr: один код завершения не доказывает, что векторы созданы для всех артефактов.
