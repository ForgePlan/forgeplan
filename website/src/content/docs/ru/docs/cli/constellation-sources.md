## Снимок CLI help

Источник: `forgeplan 0.39.0+constellation.s1.1`, `forgeplan constellation sources --help`.

```text
List the sources of a constellation (default: active)

Usage: forgeplan constellation sources [OPTIONS]

Options:
      --of <OF>  Constellation to inspect (default: the active one)
  -h, --help     Print help
  -V, --version  Print version
```
