Возвращает записи журнала активности рабочего пространства
(`.forgeplan/logs/tools-YYYY-MM-DD.jsonl`), которые подходят под заданные фильтры.
Журнал содержит имя инструмента, хеш аргументов, статус, длительность и рабочее
пространство; сведения о клиенте и исходные аргументы записываются опционально.
Он помогает расследовать операции и восстановить последовательность вызовов, но не
содержит расход токенов, стоимость API или поле класса ошибки. Длительность и число
вызовов дают лишь косвенные сведения при расследовании расходов LLM.

**Категория**: Наблюдаемость и аудит

## Когда агент вызывает

- После прерывания сессии - «какие инструменты я запускал в последний час?».
- Перед вызовом деструктивной операции - убедиться, что предыдущая завершилась и не
  повторилась по ошибке.
- Когда пользователь спрашивает «куда ушли токены?» - углубиться в самые медленные / частые
  инструменты.
- Чтобы построить судебный след для `Note` после починки хрупкого workflow.

## Входные параметры

| Имя | Тип JSON | Обязательно | Описание и ограничения |
|---|---|---|---|
| `limit` | `integer \| null` | нет | Оставить N самых свежих записей. По умолчанию 500, максимум 5000. По умолчанию в схеме: `null`. `format`: `uint32`. `minimum`: `0`. |
| `since_hours` | `integer \| null` | нет | Окно в часах назад от текущего момента: 1 = последний час, 24 = последние сутки. Описание схемы указывает, что пропуск ограничивает выборку сегодняшним днём. Значения 1–720 (30 дней). По умолчанию в схеме: `null`. `format`: `uint32`. `minimum`: `0`. |
| `status` | `string \| null` | нет | Фильтр по статусу: `ok`, `tool_err` или `rpc_err`. Без фильтра возвращаются все статусы. По умолчанию в схеме: `null`. |
| `tool` | `string \| null` | нет | Фильтр по имени инструмента. Несколько имён разделяются запятой, например `"forgeplan_score,forgeplan_activate"`. По умолчанию в схеме: `null`. |
| `workspace` | `string \| null` | нет | Необязательный явный каталог рабочего пространства для этого вызова. Сервер ищет `.forgeplan/` по этому пути, а не в каталоге запуска. Используйте для агента в отдельном git worktree. PRD-078 / ADR-015. Принимает абсолютный путь или путь с `~`. По умолчанию в схеме: `null`. |

Обязательное поле означает, что ключ должен присутствовать. Значение `null` допустимо только тогда, когда оно перечислено в типе JSON. Значения по умолчанию в схеме не обязательно совпадают с теми, которые использует обработчик и описывает текст.

_Источник схемы: MCP `tools/list`, Forgeplan 0.38.0, `inputSchema`._

## Возвращает

Успех передаётся как JSON внутри текстового содержимого MCP. Значения ниже условные.

```json
{
  "entries": [
    {
      "ts": "2026-04-26T10:14:22Z",
      "tool": "forgeplan_score",
      "args_hash": "a1b2c3d4e5f6",
      "workspace": "/work/project/.forgeplan",
      "status": "ok",
      "duration_ms": 142
    }
  ],
  "total_scanned": 312,
  "returned": 1,
  "warnings": [],
  "since_hours": 24,
  "_next_action": "1 entries in window. Busiest: `forgeplan_score`. Per-tool breakdown: `forgeplan_activity_stats`."
}
```

Подсказка `_next_action` направляет агента к правильному следующему шагу
(`forgeplan_activity_stats` для агрегатов или более узкий фильтр `tool=`).

Обработчик по умолчанию берёт последние **24 часа**, несмотря на описание схемы
про сегодняшний день. `since_hours` ограничивается диапазоном 1–720, `limit` — 1–5000.
После отбора N последних записей порядок остаётся хронологическим.
`total_scanned` считает строки до фильтрации, включая повреждённые.
`warnings` сообщает об ошибках разбора; отсутствующие дневные файлы не добавляют записей.
`client_info` (`name`, необязательный `version`) и `args` отсутствуют, если не были записаны.
Неизвестный статус просто не находит записей. Ошибки выбора пространства возвращаются
как ошибки инструмента; ошибки чтения журнала — как ошибки JSON-RPC, не пустой успех.

## Пример вызова

## Типичная последовательность

1. `forgeplan_activity_stats` - быстрый агрегат, чтобы найти загруженные / медленные инструменты.
2. `forgeplan_activity tool=<top>` - углубиться в записи конкретного инструмента.
3. Если деструктивная операция всплыла неожиданно: [`forgeplan_undo_last`](/ru/docs/mcp/forgeplan_undo_last/).

## CLI эквивалент

```bash
forgeplan activity --since-hours 24 --status tool_err --limit 50 --json
```

[`forgeplan activity`](/ru/docs/cli/activity/) читает те же JSONL-журналы. Опция CLI `--since-hours` соответствует MCP-полю `since_hours`.
