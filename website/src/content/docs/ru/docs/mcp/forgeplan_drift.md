Проверяет активные ADR/RFC на коммиты Git, затронувшие заявленные пути после даты создания артефакта. Совпадение — повод пересмотреть решение, а не доказательство неверного обоснования. Чистый отчёт не устанавливает отсутствие незакоммиченных изменений или ошибок запуска Git.

**Категория**: Качество

## Когда агент вызывает его

-   **Ежеквартальный аудит** - поиск ADR, которые больше не соответствуют коду.
-   **Перед тем как объявить ADR авторитетным** - убедитесь, что затронутые файлы не были переписаны.
-   **Перед рефакторингом** - проверьте, регулируются ли ваши целевые файлы дрейфующим ADR, и сначала обновите его.
-   **Подготовка к релизу** - убедитесь, что никакие архитектурные решения не являются незаметно просроченными.

Реализация извлекает пути из разделов тела `## Affected Files`, `## Affected Scope`, `## affected_files` и выполняет `git log --since <created_at> -- <pattern>`. Она не сравнивает mtime файловой системы или поле LanceDB `modified_at` для каждого файла.

## Входные параметры

_Входные параметры отсутствуют. Вызовите этот инструмент с пустым объектом `{}`._

## Возвращает

Ответ содержит `total`, `stale`, `reports` по всем проверенным решениям, не только с дрейфом. В отчёте есть `artifact_id`, `artifact_title`, `created_at`, `affected_files`, `changed_files` (`path`, `last_modified`), `is_stale`.

Иллюстративный пустой ответ:

```json
{ "total": 0, "stale": 0, "reports": [] }
```

Пустой отчёт может означать отсутствие активных ADR/RFC с распознанными разделами путей. Он не подтверждает согласованность реализации и документации.

```json

```

## Типичная последовательность

1.  `forgeplan_drift` - перечислить дрейфующие решения.
2.  `forgeplan_get` каждый ADR - прочитать исходное обоснование.
3. Проверьте, противоречит ли изменение обоснованию; при необходимости заместите решение или запишите, почему оно остаётся верным.
4. При необходимости повторите проверку, но продление срока не стирает историю Git и не меняет сравнение с датой создания.

## Эквивалент CLI

```bash
forgeplan drift
```
