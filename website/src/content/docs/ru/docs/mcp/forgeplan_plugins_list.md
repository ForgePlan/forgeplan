Перечисляет установленные плагины, обнаруженные на диске (плагины Claude + agentskills + Cursor) + отсутствующие записи из расширенного реестра. PRD-067 AC-1. Сканирование файловой системы только для чтения.

**Категория**: Прочее

Инструмент перечисляет **записи встроенного реестра, обнаруженные на диске**, и **необнаруженные записи**. Это не каталог всех установленных плагинов и не список работающих агентов. `missing` — необязательная возможность, а не долг пользователя по установке, пока она не нужна выбранному процессу. Ни регистрация, ни найденный путь не доказывают, что хост загрузил агента или может его запустить.

## Пример вызова

Аргументы этого инструмента, а не оболочка JSON-RPC. Замените условные ID, идентификаторы сессий и пути значениями из своего рабочего пространства. Соответствие схеме не отменяет проверки рабочего пространства, жизненного цикла и согласия на выполнение.

```json
{}
```

## Что делает

1. **Загружает расширенный реестр** - статический список плагинов, суб-агентов и наборов навыков, которые forgeplan умеет обнаруживать или рекомендовать, каждый с требованием к версии, ожидаемыми путями, командой установки и описанием.
2. **Сканирует файловую систему** по этому реестру: для каждой записи проверяется каждый ожидаемый путь под каждым из корневых каталогов поиска этого источника, пока один из них не будет найден. Первое совпадение побеждает, поэтому плагин, присутствующий в двух местах, всё равно сообщается один раз.
3. **Читает строку версии** из `manifest.json`, `plugin.json`, затем YAML frontmatter `SKILL.md`. При отсутствующих/нечитаемых метаданных версия опускается; некорректный semver всё равно может вернуться строкой `detected_version`. Совместимость проверяют doctor/info, не этот сканер.
4. **Разделяет два списка.** Записи с совпадением в файловой системе попадают в `installed` с обнаруженным путём и версией; всё остальное попадает в `missing` только как запись статического реестра.
5. **Подсказывает следующий вызов**: `forgeplan_plugins_info` для одного из обнаруженных плагинов (первого, который выдало сканирование), или `forgeplan_plugins_doctor`, когда ничего не было обнаружено, а в реестре всё ещё есть пробелы.

Ничего не записывается и ничего не устанавливается. Это сканирование, а не установщик.

## Где ищет

| Источник | Значение в ответе | Корневые каталоги поиска |
|---|---|---|
| Плагин Claude Code | `claude-plugin` | `~/.claude/plugins/cache/`, `.claude/plugins/` |
| Навык agentskills.io | `agent-skills` | `.agentskills/`, `~/.agentskills/` |
| Навык Cursor | `cursor` | `.cursor/skills/` |
| Встроено в forgeplan | `forgeplan` | не сканируется |
| Предоставлено пользователем | `manual` | не сканируется |

Относительные корневые пути разрешаются относительно рабочего каталога сервера, поэтому локальный для проекта `.claude/plugins/` находится так же, как и кеш на уровне пользователя. Сама запись `forgeplan` синтетическая: она всегда сообщается как установленная, с путём `(built-in)` и версией запущенного бинарника.

## Входные параметры

_Объявленных входных полей нет. Вызывайте инструмент с пустым объектом `{}`._

_Источник схемы: MCP `tools/list`, Forgeplan 0.38.0, `inputSchema`._

## Возвращает

Успех — JSON в текстовом содержимом MCP с `installed`, `missing`,
`installed_count`, `missing_count`, `_next_action`. Входного `workspace`
и трассировки пространства нет. Отсутствующие корни/манифесты пропускаются,
не дают ошибок инструмента.

Исторический снимок ответа 0.37.0, сокращённый для отображения. Эти количества относятся к конкретной машине, не к числу публичных плагинов или текущей версии релиза.

```json
{
  "_next_action": "forgeplan_plugins_info name=\"forgeplan\"",
  "installed": [
    {
      "detected_path": "(built-in)",
      "detected_version": "0.37.0",
      "info": {
        "description": "Forgeplan core methodology engine (always present)",
        "expected_paths": [],
        "install_command": "(built-in)",
        "name": "forgeplan",
        "source": "forgeplan",
        "version_req": "*"
      }
    }
  ],
  "installed_count": 1,
  "missing": [
    {
      "description": "C4 model diagrams (context/container/component/code) generator",
      "expected_paths": ["c4-architecture"],
      "install_command": "/plugin install c4-architecture@claude-code-workflows",
      "name": "c4-architecture",
      "source": "claude-plugin",
      "version_req": ">=1.0"
    }
  ],
  "missing_count": 11
}
```

Массив `missing` здесь сокращён до одной записи; счётчики взяты с машины, где был обнаружен только встроенный плагин. Запись `installed` всегда вкладывает полную статическую запись `info` вместе с доказательствами времени выполнения (`detected_path`, `detected_version`), чтобы вызывающая сторона могла сравнить найденное с требуемым.

`detected_version` полностью опускается, когда ни один манифест не опубликовал версию.

## Когда агент вызывает это

- **Перед рекомендацией установки** - никогда не говорите пользователю добавить плагин, который уже присутствует.
- **После установки**, чтобы подтвердить, что обнаружение действительно его подхватило (и в какой версии).
- **Когда нужна необязательная возможность** — изучите её запись через `forgeplan_plugins_info` и актуальные публичные инструкции перед рекомендацией установки.
- **Как дешёвый зонд окружения** в начале сессии, чтобы записать, какие наборы плагинов доступны на этой машине.

## Примечания

- Только чтение, неразрушающий и идемпотентный. Изменения файловой системы меняют результат, а порядок HashMap-реестра нестабилен; перед сравнением снимков сортируйте по `info.name` / `name`.
- Сканер никогда не паникует при отсутствующем или нечитаемом каталоге - отсутствующий корневой каталог поиска просто ничего не вносит. Плагин, который не может быть доказан как присутствующий, сообщается как отсутствующий.
- Обнаружение по пути, а не по lockfile: каталог плагина, который существует, но не содержит разбираемого манифеста, всё равно считается установленным, с опущенной версией.
- Реестр фиксирован во время сборки для данной версии forgeplan, поэтому недавно опубликованный набор плагинов не появляется в `missing`, пока forgeplan не будет обновлён.
- Подсказки установки — скомпилированные строки, не живой поиск marketplace. Они не подтверждают текущую публикацию, активацию в хосте или реализацию core MCP-обработчика.
