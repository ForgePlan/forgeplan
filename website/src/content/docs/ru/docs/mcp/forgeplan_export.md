Создаёт JSON-пакет сохранённых артефактов, их Markdown-тел и графа связей. Это экспорт данных артефактов, а не полная копия всех файлов пространства. Получите его в ответе для обработки или запишите по явно выбранному пути; до передачи другим изучите содержимое.

**Категория**: Рабочее пространство и данные

## Когда агент вызывает эту функцию

-   **Резервное копирование** перед рискованной операцией, такой как повторная инициализация `forgeplan init`, обновление схемы или массовое удаление - главная защита от потери артефактов.
-   **Передача между машинами** - передайте зашифрованный JSON-объект на машину другого разработчика и восстановите его с помощью `forgeplan_import`.
-   **Заполнение CI** - сделайте снимок эталонного рабочего пространства один раз и загружайте его в каждый запуск конвейера детерминированно.
-   **Аудит / соответствие** - зафиксируйте состояние решений на границе релиза для отслеживаемости.
-   **Отладка самого ForgePlan** - прикрепите экспорт к отчету об ошибке, чтобы сопровождающие могли воспроизвести точное состояние рабочего пространства.

## Примечания по безопасности

- Чтение артефактов не меняет их, но `output` записывает файл и без запроса перезаписывает существующий. Относительный путь считается от каталога проекта, содержащего выбранный `.forgeplan/`; абсолютные пути допустимы. Родительские каталоги должны уже существовать.
- Локальная конфигурация и ключи провайдеров, рекомендательные фазы, захваты, сессии исследования, корзина восстановления и производные индексы не включаются. Тела артефактов экспортируются дословно и могут содержать чувствительные данные.
- Обработчик читает записи и связи без блокировки изменений; не считайте снимок атомарным при работающих конкурентных писателях.
- CLI `forgeplan reindex` пересобирает производный индекс из отслеживаемых проекций. `scan-import` импортирует произвольный Markdown, а не этот пакет.
- Перед деструктивной операцией сохраните экспорт и отдельно нужные локальные файлы. Подсказка в ответе не разрешает закоммитить чувствительный пакет, переинициализировать сохранившееся пространство или автоматически запустить импорт.

## Входные параметры

| Имя | Тип JSON | Обязательно | Описание и ограничения |
|---|---|---|---|
| `output` | `string \| null` | нет | Необязательный путь выходного файла. Если опущен, JSON возвращается в ответе. По умолчанию в схеме: `null`. |
| `workspace` | `string \| null` | нет | Необязательный явный каталог рабочего пространства для этого вызова. Сервер ищет `.forgeplan/` по этому пути, а не в каталоге запуска. Используйте для агента в отдельном git worktree. PRD-078 / ADR-015. Принимает абсолютный путь или путь с `~`. По умолчанию в схеме: `null`. |

Обязательное поле означает, что ключ должен присутствовать. Значение `null` допустимо только тогда, когда оно перечислено в типе JSON. Значения по умолчанию в схеме не обязательно совпадают с теми, которые использует обработчик и описывает текст.

_Источник схемы: MCP `tools/list`, Forgeplan 0.38.0, `inputSchema`._

## Возвращает

С `output` ответ содержит `written_to` (итоговый путь), `artifacts` и `relations` (счётчики), а также `_next_action`.

Без `output` возвращаются `version: 1`, массивы `artifacts` и `relations`, а также `_next_action`. Версия относится к формату экспорта, не к релизу Forgeplan. Каждый объект артефакта содержит `id`, `kind`, `status`, `title`, `body`, `depth`, `author`, `parent_epic`, `r_eff_score`, `valid_until`, `created_at`, `updated_at`. Объекты связей содержат `source`, `target`, `relation`.

Оба пути не добавляют трассировку рабочего пространства. Ошибки хранилища, чтения и записи — это ошибки, а не успешный пустой пакет. Для большого пространства предпочтителен файл, чтобы не раздувать текстовый ответ MCP.

## Типичная последовательность

Резервная копия: вызвать `forgeplan_export` с выбранным `output` → сохранить пакет и отдельно нужные файлы пространства → выполнить только согласованную операцию.

Для миграции инициализируйте только действительно новый каталог назначения, прочитайте сохранённый пакет и передайте его **JSON-содержимое строкой `data`** в `forgeplan_import`. Если в клоне уже есть отслеживаемые проекции артефактов, используйте CLI `forgeplan reindex`, а не повторную инициализацию.
