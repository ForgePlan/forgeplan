title: forgeplan_release
description: "Снять рекомендательный захват артефакта; force явно разрешает обход проверки держателя."
---

Удаляет `.forgeplan/claims/<id>.yaml`, а не артефакт, блокировку исходного файла или процесс Forgeplan. По умолчанию отказывает, если **действующий** захват держит другой агент; истёкший захват можно удалить. `force: true` — явное исключение оркестратора для подтверждённо оставленного захвата, не автоматический шаг восстановления. Отсутствующий захват становится no-op только после проверки ID и идентификации. Блокировка пространства упорядочивает конкурентные вызовы claim/release.

**Категория**: Совместная работа агентов

## Когда агент вызывает

- Работник заканчивает артефакт и освобождает слот для следующего раунда диспатча.
- Работник упал / превысил TTL - оркестратор force-релизит с `agent: null, force: true`.
- Ошибочный клейм: агент схватил не тот ID, немедленно релизит для повтора.
- Уборка в конце сессии: пройтись по активным клеймам и снять каждый перед выходом.

## Входные параметры

| Имя | Тип JSON | Обязательно | Описание и ограничения |
|---|---|---|---|
| `agent` | `string \| null` | нет | Идентификатор агента. Описание схемы требует его без `force=true`; обработчик также может взять идентификатор из MCP-handshake. |
| `force` | `boolean` | нет | Принудительно освободить захват независимо от держателя. Средство восстановления для оркестратора. По умолчанию в схеме: `false`. |
| `id` | `string` | да | - |
| `workspace` | `string \| null` | нет | Необязательный явный каталог рабочего пространства для этого вызова. Сервер ищет `.forgeplan/` по этому пути, а не в каталоге запуска. Используйте для агента в отдельном git worktree. PRD-078 / ADR-015. Принимает абсолютный путь или путь с `~`. |

Обязательное поле означает, что ключ должен присутствовать. Значение `null` допустимо только тогда, когда оно перечислено в типе JSON. Значения по умолчанию в схеме не обязательно совпадают с теми, которые использует обработчик и описывает текст.

_Источник схемы: MCP `tools/list`, Forgeplan 0.38.0, `inputSchema`._

## Возвращает

Успешный ответ содержит `id`, `released: true`, `force`, `resolved_workspace`, `resolved_via` и `_next_action`. `released: true` возвращается и при отсутствии захвата; это не доказательство существования файла.

Другой действующий держатель вызывает текст ошибки MCP, например `claim held by worker-2, not you`, с рекомендательной подсказкой. JSON-объекта `ok: false` / `error` нет.

## Проверки и побочные эффекты

- `force` по умолчанию равен `false`. Явный непустой `agent` приоритетнее идентификации из handshake MCP. Без обоих обычный вызов отказывает, даже если файла захвата нет.
- Принудительный вызов допускает отсутствие `agent` и handshake-идентификации. Он удаляет координационный файл независимо от держателя. Интерактивного подтверждения нет: до переопределения нужно разрешение.
- Без force применяются проверки идентификации, а ID проверяется в любом случае. Строка агента нормализуется trim; действующий держатель должен совпадать точно. Истечение срока снимает ограничение держателя, но не требование допустимой идентификации вызывающего.
- Снимается только рекомендательный захват. Вызов не останавливает работающего агента, не отменяет его изменения и не удостоверяет завершение работы над артефактом.

## Пример вызова

Аргументы этого инструмента, а не оболочка JSON-RPC. Замените условные ID, идентификаторы сессий и пути значениями из своего рабочего пространства. Соответствие схеме не отменяет проверки рабочего пространства, жизненного цикла и согласия на выполнение.

```json
{
  "id": "RFC-001",
  "agent": "worker-1"
}
```

## Типичная последовательность

1. [`forgeplan_dispatch`](/ru/docs/mcp/forgeplan_dispatch/) → бакеты на агента.
2. [`forgeplan_claim`](/ru/docs/mcp/forgeplan_claim/) → работник лочит голову своего бакета.
3. Работник делает работу с артефактом / кодом.
4. `forgeplan_release` → освободить слот.
5. Оркестратор пере-диспатчит.

## CLI эквивалент

[`forgeplan release <id>`](/ru/docs/cli/) - те же семантики.
