Снимок интерфейса: `forgeplan 0.39.0+constellation.s1.1`.

**full сохраняет запись.** Дополнительный профиль constellation-read её не заменяет. Числа ниже — зарегистрированные инструменты, не число проверенных end-to-end сценариев. Некоторые инструменты требуют плагин.

## `constellation-read` — 9 инструментов

```bash
forgeplan serve --profile constellation-read
```

| Инструмент | Назначение из tools/list |
|---|---|
| [`constellation_close`](/ru/docs/mcp/constellation_close/) | Close a scope or snapshot handle. After closing, reads through                        it answer `snapshot_expired`/`unknown_handle` — there is no way                        to re-read fresh bytes under a dead handle. |
| [`constellation_get`](/ru/docs/mcp/constellation_get/) | Fetch one artifact by canonical key or display id. A `key@fragment`                        qualifier narrows the scope first; an unqualified id claimed by                        two sources answers `ambiguous` with the claimers. |
| [`constellation_graph`](/ru/docs/mcp/constellation_graph/) | The relation graph of the scope's live sources or a snapshot's                        pinned revisions: every artifact as a source-qualified node,                        every declared link as a typed edge carrying its relation and                        the source/file that declared it. Bounded — `truncated` marks                        a view cut at the limit, `partial` marks sources that did not                        answer. |
| [`constellation_impact`](/ru/docs/mcp/constellation_impact/) | Explainable impact: who depends on the artifact, by which                        relation path, and where the bounded walk stopped. `based_on`                        and friends propagate transitively; `references`/`informs`                        only mark the direct neighbor. |
| [`constellation_open`](/ru/docs/mcp/constellation_open/) | Open a read scope: resolve a named (or the active) constellation's                        source list once and return an opaque `scope-…` handle. Later reads                        use the handle — the source set cannot widen mid-session even if                        `constellation use` moves elsewhere. |
| [`constellation_pack`](/ru/docs/mcp/constellation_pack/) | Build a budgeted ContextPack for a task over the scope's live                        sources or a snapshot's pinned revisions: lexically ranked                        evidence units with roles, named omissions and a spend receipt. |
| [`constellation_search`](/ru/docs/mcp/constellation_search/) | Lexical search across the scope's live sources or a snapshot's                        pinned revisions. Each hit names its source and the version it                        was read at. |
| [`constellation_snapshot`](/ru/docs/mcp/constellation_snapshot/) | Pin the scope's git sources at their current HEAD and return a                        `snap-…` handle. Non-git sources are recorded in the lockfile as                        skipped — a snapshot read reports them, it does not silently                        read them live. |
| [`constellation_sources`](/ru/docs/mcp/constellation_sources/) | List the sources bound to a scope handle. |
