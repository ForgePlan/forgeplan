Показать компактный дашборд статуса проекта - общее количество артефактов, а также их количество, сгруппированное по типу и статусу. Это более легковесная альтернатива `forgeplan_health`, когда вам нужна только числовая сводка без анализа слепых пятен / сирот.

**Категория**: Дашборды и Графы

## Когда агент вызывает его

- **Быстрая проверка работоспособности** - сколько артефактов существует, сколько из них активных по сравнению с черновиками.
- **Отслеживание прогресса в спринтах** - сравнение количества с предыдущим базовым уровнем.
- **Ответ на вопрос "что находится в этом рабочем пространстве?"** без запуска полного сканирования состояния.
- **Быстрый путь** в случаях, когда `forgeplan_health` слишком ресурсоёмкий (например, для больших рабочих пространств).

Если вам нужны долги / риски / следующие действия, вместо этого вызовите `forgeplan_health`.

## Входные параметры

_Объявленных входных полей нет. Вызывайте инструмент с пустым объектом `{}`._

_Источник схемы: MCP `tools/list`, Forgeplan 0.38.0, `inputSchema`._

## Возвращает

Успех — JSON в текстовом содержимом MCP. Условные значения:

```json
{
  "project": "billing-service",
  "workspace": "/work/billing-service/.forgeplan",
  "total": 3,
  "by_kind": [
    { "kind": "note", "count": 1 },
    { "kind": "prd", "count": 2 }
  ],
  "by_status": [
    { "status": "active", "count": 1 },
    { "status": "draft", "count": 2 }
  ],
  "_next_action": "2 drafts pending. List them: `forgeplan_list status=draft`."
}
```

`by_kind` и `by_status` — массивы `{kind, count}` и `{status, count}`, не словари.
Они отсортированы по названию группы; отсутствующие группы не выводятся.
Пустое пространство возвращает `total: 0` и пустые массивы. Это сохранённые статусы
артефактов, не вычисляемая health свежесть доказательств. Подсказка предлагает routing
для пустого пространства, список черновиков, когда их больше активных, иначе health.

Входного `workspace` и трассировки `resolved_via` / `resolved_workspace` здесь нет.
Выходное `workspace` показывает выбранный каталог. Ошибки выбора пространства —
ошибки инструмента; ошибки конфигурации и чтения хранилища — ошибки JSON-RPC.

## Пример вызова

Аргументы этого инструмента, а не оболочка JSON-RPC. Замените условные ID, идентификаторы сессий и пути значениями из своего рабочего пространства. Соответствие схеме не отменяет проверки рабочего пространства, жизненного цикла и согласия на выполнение.

```json
{}
```

## Типичная последовательность

1. `forgeplan_status` - получить количество.
2. `forgeplan_list` с фильтром по `kind` / `status` - детализация по конкретному срезу.
3. `forgeplan_get` - прочитать конкретный артефакт.

## Эквивалент CLI

```bash
forgeplan status
```
