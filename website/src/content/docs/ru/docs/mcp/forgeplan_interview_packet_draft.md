**В Forgeplan 0.38.0 этот инструмент всегда возвращает `not_implemented`, если разрешение рабочего пространства и получение блокировки прошли успешно.** Установка [`forgeplan-brownfield-pack`](/ru/docs/marketplace/forgeplan-brownfield-pack/) не заменяет и не включает обработчик core: в нём нет вызова плагина. Подсказка установки в описании и ответе не доказывает, что MCP-вызов умеет создавать пакет.

Для подготовки интервью отдельно используйте опубликованный навык `interview-packager`. Не стройте интеграцию, ожидающую вопросы от этого MCP-инструмента.

**Категория**: Прочее

## Что он делает сегодня

Ровно следующее:

1. Разрешает рабочее пространство через путь записи. Ошибки выбора пространства возможны на уровне JSON-RPC.
2. Захватывает блокировку рабочего пространства.
3. Возвращает JSON-заглушку в текстовом содержимом MCP с трассировкой пространства и `_next_action`. Это успешный результат, не `isError: true`. Путь и способ выбора пространства ниже условные:

```json
{
  "_next_action": "Fix: install plugin — see marketplace issue #79 (`forgeplan-brownfield-pack`).",
  "marketplace_issue": 79,
  "message": "Install forgeplan-brownfield-pack plugin to enable; or invoke via shell pipeline temporarily.",
  "resolved_via": "param",
  "resolved_workspace": "/work/project/.forgeplan",
  "status": "not_implemented"
}
```

Он не читает артефакты для генерации интервью, не записывает артефакты интервью и не создаёт вопросы. Выбор пространства может открыть хранилище; ошибка получения блокировки возвращается как текстовая ошибка инструмента.

## Отдельный рабочий процесс marketplace

Опубликованный `forgeplan-brownfield-pack` содержит навык `interview-packager` с режимами подготовки, приоритизации, группировки и обработки ответов. Это инструкции для агента, не реализация, подключаемая к данному MCP-обработчику.

`domain` и `seed_ids` принимаются схемой, но заглушка core 0.38.0 их не читает. Здесь выполняются разрешение рабочего пространства, блокировка и возврат фиксированного ответа.

## Входные параметры

| Имя | Тип JSON | Обязательно | Описание и ограничения |
|---|---|---|---|
| `domain` | `string \| null` | нет | Предметная область или функциональная зона для пакета интервью. Схема предусматривает ограничение вопросов по этой области; core-заглушка 0.38.0 вопросы не создаёт. По умолчанию в схеме: `null`. |
| `seed_ids` | `array<string>` | нет | Необязательный список ID существующих HYP / UC / INV, задающих повестку интервью. Пустой список означает исследование с нуля в предполагаемом рабочем процессе. По умолчанию в схеме: `[]`. |
| `workspace` | `string \| null` | нет | Необязательный явный каталог рабочего пространства для этого вызова. Сервер ищет `.forgeplan/` по этому пути, а не в каталоге запуска. Используйте для агента в отдельном git worktree. PRD-078 / ADR-015. Принимает абсолютный путь или путь с `~`. По умолчанию в схеме: `null`. |

Обязательное поле означает, что ключ должен присутствовать. Значение `null` допустимо только тогда, когда оно перечислено в типе JSON. Значения по умолчанию в схеме не обязательно совпадают с теми, которые использует обработчик и описывает текст.

_Источник схемы: MCP `tools/list`, Forgeplan 0.38.0, `inputSchema`._

## Пример вызова

Аргументы этого инструмента, а не оболочка JSON-RPC. Замените условные ID, идентификаторы сессий и пути значениями из своего рабочего пространства. Соответствие схеме не отменяет проверки рабочего пространства, жизненного цикла и согласия на выполнение.

```json
{
  "domain": "billing",
  "seed_ids": [
    "HYP-001"
  ]
}
```

## Примечания

- Принятые схемой поля не означают, что функция реализована, и не гарантируют поведение будущего обработчика.
- Заглушка получает блокировку пространства, хотя не создаёт артефактов интервью.
- Ответ содержит `resolved_via` и `resolved_workspace`; это не означает, что другие инструменты возвращают такую же трассировку.
- В аннотациях инструмент идемпотентный, но не read-only. Ошибки выбора пространства и получения блокировки по-прежнему возможны.
- Рабочий путь исследования — [`forgeplan_discover_start`](/ru/docs/mcp/forgeplan_discover_start/); навыки пакета запускаются отдельно.
