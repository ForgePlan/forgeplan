**Этот инструмент - экспериментальная заглушка.** Он зарегистрирован на поверхности MCP, валидирует свой вход, а затем останавливается: реальная реализация поставляется с плагином [`forgeplan-brownfield-pack`](/ru/docs/marketplace/forgeplan-brownfield-pack/) (marketplace issue #79). Плагин отвечает за чтение расшифровки; единственная реальная работа заглушки - отклонение пути к расшифровке, который пытается выйти за пределы рабочего пространства.

Это вторая половина рабочего процесса интервью - [`forgeplan_interview_packet_draft`](/ru/docs/mcp/forgeplan_interview_packet_draft/) создаёт вопросы, этот инструмент предназначен для обработки ответов.

**Категория**: Прочее

## Что он делает сейчас

1. Разрешает рабочее пространство через путь записи, что также валидирует существование рабочего пространства.
2. Захватывает блокировку рабочего пространства.
3. Если был передан `transcript_path`, предварительно валидирует его: путь должен быть относительным к рабочему пространству и не должен содержать сегментов `..`, нулевых байтов и префиксов дисков Windows. Нарушающий путь отклоняется как ошибка MCP до выполнения любых других действий.
4. Возвращает конверт заглушки с подсказкой `_next_action`:

```json
{
  "_next_action": "Fix: install plugin — see marketplace issue #79 (`forgeplan-brownfield-pack`).",
  "marketplace_issue": 79,
  "message": "Install forgeplan-brownfield-pack plugin to enable; or invoke via shell pipeline temporarily.",
  "status": "not_implemented"
}
```

Файл не открывается, и артефакт не предлагается.

## Что он будет делать

Плагин разбирает завершённую расшифровку интервью в предложенные артефакты `HYP` (гипотезы), `UC` (сценарии использования) и `INV` (инварианты). Заглушка только проверяет путь; плагин выполняет чтение и извлечение, поэтому путь передаётся как строка относительно рабочего пространства, а не как содержимое.

## Входные параметры

| Имя | Тип | Обязательный | Описание |
|---|---|---|---|
| `transcript_path` | `string` | нет | Путь к завершённой расшифровке интервью относительно корня рабочего пространства (например, `interviews/2026-05-20.md`). Предварительно валидируется заглушкой на попытки выхода за пределы. Если не указан, заглушка всё равно возвращает свой конверт. |
| `workspace` | `string` | нет | Явный каталог рабочего пространства для этого вызова, чтобы агент в git worktree мог обратиться к своему собственному `.forgeplan/` вместо каталога запуска сервера. Абсолютный путь или путь с тильдой. |

_Источник схемы: `crates/forgeplan-mcp/src/server.rs::InterviewPacketIngestParams`_

## Валидация пути

Четыре формы отклоняются сразу, каждая как ошибка MCP с подсказкой исправления:

| Вход | Результат |
|---|---|
| `../outside/escape.md` | `` transcript_path `../outside/escape.md` is not workspace-relative `` |
| `/etc/passwd` | `` transcript_path `/etc/passwd` is not workspace-relative `` |
| `C:\interviews\a.md` | `` transcript_path `C:interviewsa.md` is not workspace-relative `` |

Проверка диска Windows существует потому, что такой путь не является абсолютным в POSIX, поэтому защита только через `is_absolute` пропустила бы его. Нулевые байты отклоняются по той же причине: большинство файловых систем отказываются от них, хотя тип пути их допускает. Это защита в глубину - плагин отвечает за фактическое чтение и также отклонил бы эти пути.

## Пример вызова

Путь, который заглушка принимает (а затем возвращает как `not_implemented`):

```json
{ "transcript_path": "interviews/2026-05-20.md" }
```

То, что плагин в конечном итоге создаст согласно своему навыку `interview-packager`, - это набор предложенных артефактов для ревью, а не артефакты, молча записанные в граф.

## Примечания

- **Эхо пути санитизировано.** Текст ошибки пропускает нарушающий путь через тот же санитайзер, который используют подсказки продвижения, поэтому управляющие символы и escape-последовательности удаляются из того, что вы видите.
- **Сделайте вызов идемпотентным.** Ничего не записывается, поэтому повторная попытка ничего не стоит; схема помечает инструмент идемпотентным по этой причине.
- **В отличие от заглушки draft, эта не возвращает разрешённое рабочее пространство.** Трассировка вычисляется и отбрасывается, поэтому если вам нужно доказательство роутинга, явно укажите `workspace` и прочитайте его обратно из другого инструмента.
- **Содержимое никогда не принимается встроенным.** Нет поля для тел расшифровок - только путь. Не проектируйте интеграцию, которая вставляет расшифровку в вызов.
- **Что использовать вместо этого сегодня:** протокол обнаружения ([`forgeplan_discover_start`](/ru/docs/mcp/forgeplan_discover_start/) плюс [`forgeplan_discover_finding`](/ru/docs/mcp/forgeplan_discover_finding/)) записывает находки в сессию, а [`forgeplan_hypothesis_promote`](/ru/docs/mcp/forgeplan_hypothesis_promote/) - это способ действовать на основе выводов интервью.
