Проверяет пути и размеры файлов для предполагаемого инжеста и возвращает подсказку команды CLI. В 0.38.0 этот MCP-обработчик не разбирает маппинг или источник, не запускает движок инжеста, не показывает черновики и не применяет изменения, даже при `dry_run: false`.

**Категория**: Прочее

Это **планировщик, не исполнитель**. Он требует существующие обычные файлы под разрешённым корнем: проектом с `.forgeplan/`, найденным от CWD процесса сервера, либо `~/.claude/plugins/`. Входного `workspace` нет. Записи в хранилище артефактов не происходит; решение о запуске подсказанной команды CLI вызывающий принимает отдельно.

## Пример вызова

Аргументы этого инструмента, а не оболочка JSON-RPC. Замените условные ID, идентификаторы сессий и пути значениями из своего рабочего пространства. Соответствие схеме не отменяет проверки рабочего пространства, жизненного цикла и согласия на выполнение.

```json
{
  "mapping": "map.yaml",
  "source": "docs/components.md",
  "dry_run": true
}
```

## Что он делает

1. **Канонизирует путь к маппингу.** Файл должен существовать, быть обычным файлом и разрешаться под разрешённым корнем: корнем рабочего пространства (родителем `.forgeplan/`) или деревом `~/.claude/plugins/`, куда пакеты плагинов устанавливают свои бандлы. Побеги через симлинки разрешаются перед проверкой, поэтому безобидный на вид относительный путь не может указывать наружу.
2. **Канонизирует путь к источнику** по тем же правилам.
3. **Проверяет бюджет размера.** Маппинг отклоняется при превышении 1 МиБ, источник - при превышении 10 МиБ. Проверка читает только метаданные файла - сервер никогда не загружает ни один из файлов в память здесь.
4. **Эхо плана.** Ответ повторяет оба пути (редактированные до относительных от рабочего пространства, где возможно), оба флага и `wave3_status: "planned"` с пустыми списками `drafts`, `skipped` и `errors`.
5. **Подсказывает реальную команду.** `_next_action` содержит готовую к вставке строку `forgeplan ingest --mapping ... --source ...`, с добавленными `--dry-run` и/или `--update` в соответствии с переданными флагами.

Шаги 1–3 проверяют пути и метаданные, не содержимое. Поэтому план может быть
возвращён даже для некорректного маппинга. Например, неподдерживаемый `source_kind`
пройдёт такую предварительную проверку, но будет отклонён при разборе в CLI.
План — не валидация схемы, не просмотр сработавших правил и не подтверждение
успешного инжеста.

## Когда агент вызывает это

- **Предварительная проверка маппинга** перед тратой запуска CLI: раннее обнаружение неверного пути или слишком большого источника.
- **Подготовка команды CLI** без изменения хранилища. Для просмотра реальных правил и черновиков отдельно запустите CLI с `--dry-run`.
- **Вопрос «какой будет команда?»** — изучите подсказку и проверьте пути перед выполнением.
- **Проверка ограничения рабочим пространством** - отказ сигнализирует, что путь, данный агенту, находится вне проекта.

## Входные параметры

| Имя | Тип JSON | Обязательно | Описание и ограничения |
|---|---|---|---|
| `dry_run` | `boolean` | нет | Plan-only - engine runs but no artifacts written. Wave 3 default. По умолчанию в схеме: `true`. |
| `mapping` | `string` | да | Путь к YAML-файлу сопоставления по схеме SPEC-004. |
| `source` | `string` | да | Путь к исходному файлу или каталогу по описанию схемы. Обработчик MCP 0.38.0 принимает только обычный файл; см. ограничения ниже. |
| `update` | `boolean` | нет | Разрешить обновление существующих артефактов при повторном импорте. По умолчанию в схеме: `false`. |

Обязательное поле означает, что ключ должен присутствовать. Значение `null` допустимо только тогда, когда оно перечислено в типе JSON. Значения по умолчанию в схеме не обязательно совпадают с теми, которые использует обработчик и описывает текст.

_Источник схемы: MCP `tools/list`, Forgeplan 0.38.0, `inputSchema`._

## Возвращает

Успех — JSON в текстовом содержимом MCP. Значения и пути ниже условные.

```json
{
  "_next_action": "forgeplan ingest --mapping map.yaml --source docs/comp.md --dry-run",
  "drafts": [],
  "dry_run": true,
  "errors": [],
  "mapping": "map.yaml",
  "skipped": [],
  "source": "docs/comp.md",
  "update": false,
  "wave3_note": "Wave 3 MCP surface validates inputs only; full ingest execution available via the `forgeplan ingest` CLI. Wave 4 will wire IngestEngine + artifact::Store directly.",
  "wave3_status": "planned"
}
```

`drafts`, `skipped` и `errors` здесь всегда пусты. Они не показывают разобранные черновики, успешные пропуски или отсутствие ошибок маппинга. `wave3_note` описывает будущую интеграцию, не функцию 0.38.0.

## Отказы

Каждый отказ - это ошибка инструмента, текст которой содержит причину плюс строку `_next_action:`:

| Отказ | Сообщение | Подсказка |
|---|---|---|
| Маппинг отсутствует или вне рабочего пространства | `mapping file not found or outside workspace` | Проверьте путь к маппингу. Маппинги SPEC-004 по соглашению находятся в `.forgeplan/mappings/*.yaml`. |
| Источник отсутствует, вне рабочего пространства или является директорией | `source path not found or outside workspace` | Проверьте, что путь к источнику существует под рабочим пространством. |
| Маппинг превышает 1 МиБ | `mapping exceeds 1048576-byte size limit` | Обрежьте маппинг или разделите на несколько файлов SPEC-004. |
| Источник превышает 10 МиБ | `source exceeds 10485760-byte size limit` | Разделите исходный файл перед инжестом. |

Отказы по путям намеренно общие и не возвращают абсолютные пути хоста. Они охватывают и рабочее пространство, и корень плагинов, несмотря на сокращённую формулировку сообщения.

## Примеры

Планирование запуска с настройками по умолчанию (`dry_run` true, `update` false):

```json
{ "mapping": "map.yaml", "source": "docs/comp.md" }
```

Указание намерения записать и разрешить обновления - подсказка получает `--update` и теряет `--dry-run`:

```json
{ "mapping": "map.yaml", "source": "docs/comp.md", "dry_run": false, "update": true }
```

Условный фрагмент ответа (полный ответ также содержит остальные поля выше):

```json
{
  "_next_action": "forgeplan ingest --mapping map.yaml --source docs/comp.md --update",
  "dry_run": false,
  "update": true,
  "wave3_status": "planned"
}
```

Указание на директорию вместо файла:

```json
{ "mapping": "map.yaml", "source": "docs" }
```

```text
source path not found or outside workspace

_next_action: Verify the source path exists under the workspace.
```

## Примечания

- Инструмент аннотирован как read-only, неразрушающий и идемпотентный; изменения инжеста не применяет.
- Пути под CWD процесса или найденным корнем пространства становятся относительными; остальные допустимые пути сокращаются до имени файла. Подсказка экранирует их для shell, но имя файла из корня плагинов может не разрешиться из CWD вашей оболочки. Перед выполнением подставьте реальный допустимый путь.
- Слишком большие файлы отклоняются по метаданным, не обрезаются. Проверки содержимого и вложенности YAML здесь нет.

## Эквивалент в CLI

- [`forgeplan ingest`](/ru/docs/cli/ingest/) — выполняет обработку с `--mapping` / `--source`, поддерживает `--dry-run`, `--update`, `--json`. Его dry-run показывает реальные черновики. Делегат плейбука `forgeplan_core:ingest` — другой путь выполнения, не этот MCP-планировщик.
