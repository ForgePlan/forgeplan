Детектор AI-слопа в тексте - обнаруживает AI-слоп и очеловечивает его на русском и английском. Два скилла базы знаний (humanizer-ru: 54 паттерна + жёсткие баны + блокировка фактов + детерминированный сканер 0-100; slop-humanizer: EN де-слоп, синтезированный из 5 репозиториев humanizer), две команды (/slop-audit детекция только для чтения, /slop-humanize полная перезапись с автоматическим роутингом языка), агент-ревьюер slop-cop, запускаемый по хуку, и подсказка PostToolUse для текстовых файлов. Используйте при очеловечивании текста, удалении AI-маркеров, де-слопинге или аудите прозы перед публикацией. Слоп в дизайне/анимации намеренно вне области видимости (выделен из antislop). v1.2.0: Каждый агент пакета получил секцию `## Model tier`: какой ЯРУС нужен его работе и почему ярус задаёт самая трудная стадия, а не самая частая. Там же сказано, что значение `model:` во фронтматтере - привязка Claude Code, а не требование: в OMP/OpenCode/Codex/Gemini этих имён нет, надо подставить модель своего яруса и при промахе промахиваться ВВЕРХ. Лестница ярусов - `docs/GUIDE-AI-SDLC-PDLC-RU.md` §6.2, здесь она не пересказывается.

**Стоимость**: лёгкая | **Стабильность**: стабильный | **Версия**: 1.2.0 | **Категория**: качество

**Цели**: claude-code

**Требует**: Ничего, кроме Claude Code

## Команды

| Команда | Что делает |
|---|---|
| `/slop-audit` | Детекция AI-слопа в тексте только для чтения. |
| `/slop-humanize` | Очеловечить текст - убрать AI-слоп и переписать в конкретном человеческом голосе. |

## Агенты

| Агент | Что делает |
|---|---|
| `slop-cop` | Ревьюер прозы, который ловит AI-слоп в русском и английском тексте. |

## Скиллы

- `humanizer-ru` - Скилл для очеловечивания русскоязычного текста.
- `slop-humanizer` - Remove AI slop from English text and write like a human.
