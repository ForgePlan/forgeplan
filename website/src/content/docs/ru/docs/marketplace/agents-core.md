Пакет из 11 инженерных агентов для реализации, ревью, тестирования, отладки, планирования и анализа производительности. `coder` меняет исходники, а `code-reviewer` и `tester` оценивают результат в отдельных контекстах и записывают Evidence. Агент `performance-engineer` фиксирует исходные и повторные замеры. Определения агентов не запускают этот цикл автоматически: последовательность вызовов выбирает оркестратор.

**Стоимость**: средняя | **Стабильность**: стабильный | **Версия**: 1.13.0 | **Категория**: developer-tools

**Цели**: claude-code

**Требует**: Claude Code и инструменты проекта для соответствующей работы. Для записи Evidence агентами, работающими с Forgeplan, нужен отдельно подключённый Forgeplan MCP и существующий workspace. Тестовые и измерительные инструменты плагин не устанавливает.

## Агенты

| Агент | Что делает |
|---|---|
| `code-reviewer` | Читает diff или набор файлов, запускает доступные проверки и записывает Evidence с вердиктом PASS/CONCERNS/BLOCKER. Сам исходники не переписывает. |
| `coder` | Агент реализации, изменяющий исходники (Profile C-coder). |
| `debugger` | Эксперт по отладке, специализирующийся на диагностике сложных проблем, анализе первопричин и систематическом решении проблем в различных языках и окружениях. |
| `error-detective` | Криминалистический исследователь ошибок, выполняющий анализ первопричин, картирование каскадных сбоев, корреляцию логов и обнаружение аномалий в распределённых и монолитных системах. |
| `performance-engineer` | Профилирует систему и записывает исходные и повторные измерения в Evidence; изменения кода передаёт исполнителю. |
| `planner` | Специалист по стратегическому планированию, который декомпозирует сложные задачи в выполнимые планы с картой зависимостей, распределением агентов, оценкой сроков и снижением рисков. |
| `production-validator` | Валидатор готовности к продакшену, который обнаруживает mock/stub/fake реализации в релизном коде, проверяет реальные интеграции с базами данных и внешними API, валидирует конфигурацию окружения и выполняет чеклист готовности к развёртыванию (качество кода, безопасность, мониторинг, производительность). |
| `researcher` | Специалист по глубокому исследованию и анализу, который изучает кодовые базы, выявляет архитектурные паттерны и антипаттерны, картирует зависимости и синтезирует находки в практические рекомендации. |
| `reviewer` | Специалист по ревью кода и обеспечению качества, который находит баги, уязвимости безопасности, проблемы дизайна и нарушения стандартов через систематическую проверку. |
| `tdd-london` | Специалист по TDD London School, ведущий разработку снаружи-внутрь с mock-driven дизайном, верификацией поведения и тестированием взаимодействий для чистой коллаборации объектов. |
| `tester` | Запускает тесты, сопоставляет результаты и покрытие с критериями приёмки и записывает Evidence. |

В версии 1.13.0 нет отдельных файлов команд, навыков и регистраций хуков. Роли и ограничения агентов описаны для среды исполнения; перенос текста агента в другую среду не переносит автоматически её разрешения. Активация Evidence остаётся действием оркестратора, а не побочным эффектом отчёта ревьюера.


## Установка

```bash
/plugin marketplace add ForgePlan/marketplace
/plugin install agents-core@ForgePlan-marketplace
```
