Профессиональные специализированные агенты: проверка безопасности и prompt-injection, обнаружение PII, архитектурная и системная ревью уровня staff, гейт-хранитель перед активацией, авторы ADR и спецификаций, аналитики-исследователи и инфраструктурные роли. Используйте, когда задача требует именованного эксперта, а не универсала - прохода OWASP/STRIDE, архитектурной фитнес-ревью, решения, записанного как ADR, или последнего гейта перед активацией артефакта. Полная история в CHANGELOG.md.

**Стоимость**: тяжёлая | **Стабильность**: стабильная | **Версия**: 1.30.0 | **Категория**: developer-tools

**Цели**: claude-code

**Требует**: Ничего, кроме Claude Code

## Агенты

| Агент | Что делает |
|---|---|
| `adr-architect` | Специалист по ADR, использующий формат MADR 3.0. |
| `api-docs-engineer` | Специалист по документации OpenAPI - генерирует и поддерживает спецификации OpenAPI 3.0 из существующего кода API, документирует эндпоинты с примерами, схемами, ответами об ошибках и руководствами по аутентификации. |
| `architect-reviewer` | Архитектурный ревьюер (гейт-стиль Profile B). |
| `artifact-author` | Универсальный создатель Profile A для любого типа артефакта forgeplan. |
| `artifact-maintainer` | Универсальный фоллбэк Profile D для агностического к типу обслуживания метаданных СУЩЕСТВУЮЩИХ артефактов forgeplan. |
| `artifact-reviewer` | Универсальный ревьюер Profile B для аудита ЗДОРОВЬЯ артефакта forgeplan - полнота схемы, связность секций, здоровье графа связей, свежесть/устаревание, доверие R_eff. |
| `brief-intake` | Специалист по первичному приёму запросов. |
| `claims-authorizer` | Специалист по авторизации на основе утверждений - проектирует политики ABAC/RBAC, оценивает утверждения доступа, обеспечивает детализированные разрешения и ведёт аудиторские журналы, используя модель из 5 утверждений. |
| `code-analyzer` | Специалист по анализу качества кода, выполняющий комплексные ревью в пяти областях - качество, производительность, безопасность, архитектура и технический долг. |
| `ddd-domain-expert` | Специалист по Domain-Driven Design для стратегического и тактического доменного моделирования - идентификация ограниченных контекстов, проектирование агрегатов, обеспечение единого языка и картирование контекстов. |
| `distributed-systems-expert` | Эксперт по теории и практике распределённых систем - протоколы консенсуса (Raft, PBFT, Paxos), CRDT, протоколы gossip, управление кворумом и распределённая безопасность. |
| `documentation-engineer` | Инженер документации - проектирует информационную архитектуру, создаёт документацию API, туториалы и справочные руководства с автоматизацией, оптимизацией поиска и поддержкой множественных версий. |
| `evidence-gatherer` | Активный сборщик доказательств для оценки Trust Calculus. |
| `evidence-recorder` | Фоллбэк-агент Profile B для фаз, которые производят доказательства, но не подходят под специализированного регистратора (code-reviewer / tester / security-expert / architect-reviewer / system-dev). |
| `goal-planner` | Специалист по целеориентированному планированию действий (GOAP). |
| `guardian` | Гейт перед активацией (гейт-стиль Profile B). |
| `injection-analyst` | Аналитик prompt injection и jailbreak - обнаруживает, классифицирует и смягчает угрозы инъекций в приложениях на базе LLM, используя таксономию из 6 типов угроз, обнаружение уклонений и оценку сложности. |
| `mcp-developer` | MCP-разработчик, специализирующийся на реализации серверов и клиентов Model Context Protocol - JSON-RPC 2.0, SDK для TypeScript/Python, определения инструментов/ресурсов/промптов, конфигурация транспорта (stdio/SSE) и продакшн-развёртывание. |
| `memory-specialist` | Специалист по векторной памяти и оптимизации извлечения - индексирование HNSW, квантизация векторов, гибридный поиск с RRF-слиянием, консолидация памяти и стратегии защиты знаний. |
| `microservices-architect` | Архитектор распределённых систем для проектирования микросервисов - идентификация границ сервисов, паттерны коммуникации (синхронные/асинхронные), паттерны устойчивости, стеки наблюдаемости, развёртывание Kubernetes и декомпозиция монолита в микросервисы. |
| `ml-developer` | ML-разработчик, специализирующийся на end-to-end рабочих процессах машинного обучения - предобработка данных, выбор модели, кросс-валидация, настройка гиперпараметров, оценка и подготовка к развёртыванию с использованием scikit-learn, pandas и фреймворков глубокого обучения. |
| `pii-detector` | Детектор PII и учётных данных - сканирует код, конфигурационные файлы, логи и тестовые фикстуры на утечки чувствительных данных, используя регулярные выражения для API-ключей, паттерны PII и соответствие требованиям (GDPR, HIPAA, PCI-DSS, SOC2). |
| `platform-engineer` | Платформенный инженер, специализирующийся на внутренних платформах для разработчиков - самообслуживаемая инфраструктура, рабочие процессы GitOps, шаблоны golden path, портал разработчика Backstage и оптимизация опыта разработчиков. |
| `prompt-engineer` | Экспертный промпт-инженер, специализирующийся на проектировании, оптимизации и оценке промптов для LLM - паттерны промптов (zero-shot, few-shot, CoT, ReAct), оптимизация токенов, механизмы безопасности и фреймворки A/B-тестирования. |
| `research-analyst` | Аналитик-исследователь только для чтения. |
| `search-specialist` | Специалист по поиску, владеющий продвинутым извлечением информации и обнаружением знаний - формулирование запросов, выбор источников, паттерны Grep/Glob, составные стратегии поиска и курирование результатов в кодовых базах, логах и документации. |
| `security-expert` | Специалист по аудиту безопасности. |
| `smith` | Мастер-оркестратор (Profile B-orchestrator). |
| `system-dev` | Финальный аудитор уровня staff/principal (гейт-стиль Profile B). |
| `ui-designer` | Визуальный дизайнер, специализирующийся на интуитивных, доступных пользовательских интерфейсах - дизайн-системы, паттерны взаимодействия, визуальная иерархия, адаптивные макеты, соответствие WCAG 2.1 AA и передача разработчикам. |
