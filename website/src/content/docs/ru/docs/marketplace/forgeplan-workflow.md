Структурированный инженерный рабочий процесс для пользователей forgeplan: `/forge-cycle` проводит один артефакт через весь конвейер до активации с применением гейтов качества на каждом этапе, а `/forge-audit` проверяет результат. Используйте, когда работа имеет стандартную глубину или выше и не должна достигать активации без доказательств, ревью и гейта - цикл отказывается продолжать, вместо того чтобы позволить тихо пропустить этап. Полная история в CHANGELOG.md.

**Стоимость**: средняя | **Стабильность**: стабильная | **Версия**: 1.23.1 | **Категория**: workflow

**Цели**: claude-code

**Требует**: CLI: forgeplan; Плагины: dev-toolkit >=1.3.0 (опционально)

## Команды

| Команда | Что делает |
|---|---|
| `/forge-audit` | Запустить мультиэкспертный аудит текущей кодовой базы. |
| `/forge-cycle` | Запустить полный инженерный цикл forgeplan: проверка здоровья, роутинг, формирование, построение, доказательства, активация, коммит. |

## Агенты

| Агент | Что делает |
|---|---|
| `forge-advisor` | Консультант по рабочему процессу Forgeplan, который предлагает методологические подсказки во время инженерных задач. |

## Навыки

- `forgeplan-methodology` - Структурированный инженерный рабочий процесс Forgeplan - планирование функций, создание PRD/RFC/ADR, проверка здоровья проекта, роутинг задач на правильную глубину, ревью артефактов, размышление перед кодированием.

## Установка

```bash
/plugin marketplace add ForgePlan/marketplace
/plugin install forgeplan-workflow@ForgePlan-marketplace
```
