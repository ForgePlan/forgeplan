`/forge-cycle` задаёт последовательность работы с артефактом: проверка состояния проекта, выбор глубины, подготовка требований, реализация, аудит, доказательства, активация и коммит. `/forge-audit` проверяет результат с нескольких инженерных позиций и записывает доказательства аудита. Этапы выполняет оркестратор через доступные инструменты; упоминания других slash-команд внутри шаблона не запускают их автоматически. Проверки CLI/MCP и правила оркестратора следует отличать от самого текста инструкции.

**Стоимость**: средняя | **Стабильность**: стабильная | **Версия**: 1.23.1 | **Категория**: workflow

**Цели**: claude-code

**Требует**: установленный `forgeplan` в `PATH` и инициализированный workspace. Для MCP-пути нужен подключённый сервер Forgeplan. Каталог указывает `dev-toolkit >=1.3.0` как необязательный плагин; для новых проектов его заменяет `fpl-skills`. Память Hindsight необязательна. Дополнительных агентов устанавливают отдельно либо оркестратор выполняет предусмотренную шаблоном работу сам.

## Команды

| Команда | Что делает |
|---|---|
| `/forge-audit` | Проверяет логику, архитектуру, безопасность и тесты; при необходимости производительность и документацию. Создаёт Evidence аудита и освобождает координационный claim. |
| `/forge-cycle` | Проводит задачу через проверку состояния, выбор глубины, подготовку артефактов, реализацию, аудит, доказательства, активацию и коммит. |

## Агенты

| Агент | Что делает |
|---|---|
| `forge-advisor` | Консультант по рабочему процессу Forgeplan, который предлагает методологические подсказки во время инженерных задач. |

## Навыки

- `forgeplan-methodology` - Объясняет планирование, PRD/RFC/ADR, выбор глубины, проверку состояния проекта, качество доказательств и порядок этапов.

## Хуки

В `hooks/hooks.json` зарегистрирован `PreToolUse`:

- для `Bash` запускается проверка опасных команд;
- для `Write` запускается проверка наличия активного PRD, если CLI и workspace доступны; она предупреждает, но не блокирует запись.

Это регистрация в Claude Code с указанными фильтрами, а не универсальная автоактивация инженерного цикла или защита всех способов записи файлов. В других средах хуки и ограничения нужно подключать отдельно.


## Установка

```bash
/plugin marketplace add ForgePlan/marketplace
/plugin install forgeplan-workflow@ForgePlan-marketplace
```
