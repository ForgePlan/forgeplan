Методология Agentic RAG для навыков Claude Code - как структурировать большие базы знаний с SKILL.md в роли тонкого роутера + sections/_index.md + файлы контента на 30-50 строк. Используйте при создании навыка с >300 строк или >5 тем. Включает 5+ анти-паттернов, готовый starter-kit для копирования и рецепты распространения. Срабатывает на: agentic RAG, структура SKILL.md, паттерн sections, методология навыков, дизайн базы знаний, как писать навык.

**Стоимость**: лёгкая | **Стабильность**: стабильный | **Версия**: 1.1.1 | **Категория**: developer-tools

**Целевые платформы**: claude-code

**Требования**: Ничего, кроме Claude Code

## Навыки

- `agentic-rag` - Методология Agentic RAG для навыков Claude Code - как структурировать большие базы знаний, используя SKILL.md как тонкий роутер, sections/_index.md как оглавление и файлы контента на 30-50 строк как фактическую базу знаний.

## Установка

```bash
/plugin marketplace add ForgePlan/marketplace
/plugin install agentic-rag@ForgePlan-marketplace
```
