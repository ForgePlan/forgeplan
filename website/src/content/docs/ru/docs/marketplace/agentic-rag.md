Методология организации больших баз знаний для навыков Claude Code. `SKILL.md` служит коротким маршрутизатором, `sections/_index.md` помогает найти тему, а файлы по 30–50 строк содержат отдельные инструкции. Такой подход подходит навыкам длиннее 300 строк или с более чем пятью темами; короткому справочнику с одной задачей дополнительная структура не нужна. Поставляются шесть разделов: выбор структуры, устройство файлов, описания и триггеры, качество текста, шаблоны и распространение.

**Стоимость**: лёгкая | **Стабильность**: стабильный | **Версия**: 1.1.1 | **Категория**: developer-tools

**Целевые платформы**: claude-code

**Требования**: Ничего, кроме Claude Code

## Навыки

- `agentic-rag` - Помогает написать навык с выборочной загрузкой нужных файлов. Это методика работы с файлами, а не сервер векторного поиска или готовая система индексации. Отдельных команд, агентов и регистраций хуков у версии 1.1.1 нет.

## Установка

```bash
/plugin marketplace add ForgePlan/marketplace
/plugin install agentic-rag@ForgePlan-marketplace
```
