[УСТАРЕЛ - замещён fpl-skills] Универсальный инженерный инструментарий: мультиэкспертный аудит, спринты на основе волн, восстановление контекста сессии, структурированные отчёты с автоматическими триггерами и хуками безопасности. Работает с любым проектом и языком. Используйте только если уже зависите от него - новым пользователям следует установить fpl-skills, который его замещает. Полная история в CHANGELOG.md.

**Стоимость**: средняя | **Стабильность**: устаревший | **Версия**: 1.9.1 | **Категория**: developer-tools

**Целевые платформы**: claude-code

**Требования**: Ничего, кроме Claude Code

**Замещён**: fpl-skills

## Команды

| Команда | Что делает |
|---|---|
| `/audit` | Мультиэкспертный аудит кода - запускает 4 параллельных агента-ревьюера (Логика, Архитектура, Безопасность, Тесты) для анализа кодовой базы и отчёта о находках по степени серьёзности. |
| `/recall` | Восстановление контекста сессии - читает состояние проекта, недавнюю историю git и доступные источники памяти, чтобы дать вам краткий брифинг в начале сессии. |
| `/report` | Генерация структурированного отчёта о недавней работе - выберите шаблон (build/audit/decision/incident/migration), примените конвенции навыка forge-report, выведите сканируемую сводку с TL;DR, что сделано, что не сделано, обратимость, риски дрейфа и следующие шаги. |
| `/sprint` | Адаптивный спринт - масштабируется от быстрого фикса до полного цикла релиза. |

## Агенты

| Агент | Что делает |
|---|---|
| `dev-advisor` | Проактивный советник по разработке, который отслеживает ваш рабочий процесс и предлагает лучшие практики. |

## Навыки

- `forge-report` - Форматы структурированных отчётов для Claude - на основе карточек, читаемые человеком, без ASCII-шума рамок.
