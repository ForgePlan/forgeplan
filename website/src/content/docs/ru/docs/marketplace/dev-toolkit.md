Устаревший инженерный инструментарий для Claude Code. Содержит команды аудита, выполнения задач волнами, восстановления контекста и структурированных отчётов. Установленные версии можно продолжать использовать; для новых проектов рекомендуется `fpl-skills`. В нём восстановление контекста называется `/restore`, а не `/recall`.

**Стоимость**: средняя | **Стабильность**: устаревший | **Версия**: 1.9.1 | **Категория**: developer-tools

**Целевые платформы**: claude-code

**Требования**: Claude Code. Команды используют доступные инструменты проекта и его тестовое окружение; Forgeplan, трекер задач и память подключаются отдельно и не обязательны для базовой работы.

**Замещён**: fpl-skills

## Команды

| Команда | Что делает |
|---|---|
| `/audit` | Мультиэкспертный аудит кода - запускает 4 параллельных агента-ревьюера (Логика, Архитектура, Безопасность, Тесты) для анализа кодовой базы и отчёта о находках по степени серьёзности. |
| `/recall` | Восстановление контекста сессии - читает состояние проекта, недавнюю историю git и доступные источники памяти, чтобы дать вам краткий брифинг в начале сессии. |
| `/report` | Выбирает шаблон build/audit/decision/incident/migration и готовит отчёт через `forge-report`: результат, ограничения, обратимость и следующие шаги. |
| `/sprint` | Адаптивный спринт - масштабируется от быстрого фикса до полного цикла релиза. |

## Агенты

| Агент | Что делает |
|---|---|
| `dev-advisor` | Предлагает аудит, тесты и подходящий масштаб спринта; не заменяет выполнение проверок. |

## Навыки

- `forge-report` - Форматы структурированных отчётов для Claude - на основе карточек, читаемые человеком, без ASCII-шума рамок.

## Хуки

`hooks/hooks.json` регистрирует в Claude Code:

- `SessionStart`: сброс счётчика для отчётов;
- `PreToolUse` с `Bash`: проверку опасных команд;
- `PostToolUse` с `Write|Edit|MultiEdit`: напоминание о тестах; отдельный обработчик учитывает вызовы для отчёта.

Это регистрация обработчиков в Claude Code, а не универсальная автоактивация команд или агентов. Подсказка о тестах не означает, что тесты были запущены.


## Установка

```bash
/plugin marketplace add ForgePlan/marketplace
/plugin install dev-toolkit@ForgePlan-marketplace
```
