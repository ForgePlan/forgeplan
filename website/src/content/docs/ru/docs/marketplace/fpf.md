First Principles Framework - усилитель мышления для структурированного рассуждения, декомпозиции систем и принятия решений, с прикладными паттернами, интеграцией с forgeplan и практическими командами. Основан на спецификации FPF Анатолия Левенчука. Используйте, когда решение требует большего, чем мнение: генерация настоящих альтернатив перед выбором одной, декомпозиция системы на ограниченные контексты или оценка доказательств вместо утверждений. Полная история в CHANGELOG.md.

**Стоимость**: средняя | **Стабильность**: стабильный | **Версия**: 1.7.1 | **Категория**: рассуждение

**Цели**: claude-code

**Требует**: Ничего, кроме Claude Code

## Команды

| Команда | Что делает |
|---|---|
| `/fpf` | First Principles Framework - универсальная команда для мышления. |
| `/fpf-decompose` | Декомпозировать сложную проблему или систему на ограниченные части с помощью FPF. |
| `/fpf-evaluate` | Оценить решение или сравнить альтернативы с помощью Trust Calculus и F-G-R оценки FPF. |
| `/fpf-lookup` | Найти концепцию FPF в базе знаний из 224 разделов. |
| `/fpf-reason` | Рассуждать над сложным вопросом или проблемой, используя цикл структурированного рассуждения FPF. |

## Агенты

| Агент | Что делает |
|---|---|
| `fpf-advisor` | Советник по мышлению FPF, который предлагает рекомендации по структурированному рассуждению для задач архитектуры, планирования и принятия решений. |
