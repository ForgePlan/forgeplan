Плагин упаковывает спецификацию First Principles Framework Анатолия Левенчука и прикладные инструкции для инженерных задач. Помогает разделить систему на части, сформулировать альтернативы, вывести проверяемые следствия и сравнить их с доказательствами. Содержит пять команд, агента `fpf-advisor` и навык `fpf-knowledge` с 224 разделами спецификации и четырьмя прикладными руководствами.

**Стоимость**: средняя | **Стабильность**: стабильный | **Версия**: 1.7.1 | **Категория**: рассуждение

**Цели**: claude-code

**Требует**: Claude Code. Для чтения базы знаний и рассуждения Forgeplan не обязателен. Для создания PRD, ADR и Evidence по результатам нужен отдельно установленный CLI или подключённый MCP-сервер Forgeplan.

## Команды

| Команда | Что делает |
|---|---|
| `/fpf` | Выбирает режим `decompose`, `evaluate`, `reason` или `lookup` по запросу. |
| `/fpf-decompose` | Декомпозировать сложную проблему или систему на ограниченные части с помощью FPF. |
| `/fpf-evaluate` | Оценить решение или сравнить альтернативы с помощью Trust Calculus и F-G-R оценки FPF. |
| `/fpf-lookup` | Найти концепцию FPF в базе знаний из 224 разделов. |
| `/fpf-reason` | Рассуждать над сложным вопросом или проблемой, используя цикл структурированного рассуждения FPF. |

## Агенты

| Агент | Что делает |
|---|---|
| `fpf-advisor` | Советник по мышлению FPF, который предлагает рекомендации по структурированному рассуждению для задач архитектуры, планирования и принятия решений. |

## Навыки

- `fpf-knowledge` - Загружает подходящие разделы FPF и помогает применить их к задаче. Регистраций хуков у версии 1.7.1 нет; рассуждение и рекомендации агента не означают автоматической записи артефактов.
