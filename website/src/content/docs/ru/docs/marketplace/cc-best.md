Практический справочник по CLAUDE.md, плагинам, агентам, хукам, MCP и антипаттернам Claude Code. Помогает при создании и разборе конфигурации, но не заменяет официальную документацию клиента: наблюдения и примеры отражают опыт авторов на момент их записи, а не гарантированное поведение любой будущей версии.

**Стоимость**: лёгкая | **Стабильность**: стабильная | **Версия**: 1.1.6 | **Категория**: знания

**Цели**: claude-code

**Требования**: Claude Code для штатной установки и загрузки навыка. CLI и MCP-серверы для чтения справочника не требуются; описанные в примерах интеграции настраиваются отдельно.

## Навыки

- `cc-best` - Лучшие практики экосистемы Claude Code - экспертный справочник по CLAUDE.md, плагинам, агентам, хукам, MCP и антипаттернам.

В пакете **1 навык**, без агентов и файлов slash-команд. Навык выбирает один из шести разделов и загружает наиболее узкий файл через его `_index.md`:

| Раздел | Содержание |
|---|---|
| `claude-md` | Структура и иерархия инструкций |
| `plugins` | Манифест, компоненты, распространение и версии |
| `agents` | Frontmatter, профили и примеры ролей |
| `hooks` | События, порядок вызовов и ошибки настройки |
| `mcp` | Интеграция, доступность инструментов и диагностика |
| `antipatterns` | Повторяющиеся ошибки по всем темам |

## Границы применения

Это база знаний, не установщик, генератор конфигурации или верификатор окружения. Установка `cc-best` не настраивает чужие хуки, не подключает MCP и не активирует агентов или артефакты.

Собственных агентов с `## Model tier` здесь нет. Примеры `model:` относятся к формату Claude Code; они не являются переносимым выбором модели в OMP, OpenCode, Codex или Gemini CLI. При переносе примера проверьте возможности и синтаксис целевого клиента отдельно.

## Хуки

Собственного `hooks/hooks.json` нет. Раздел про хуки объясняет их настройку, но сам ничего не регистрирует.
