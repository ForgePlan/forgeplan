Проводит одну отслеживаемую задачу от начала до конца в любом трекере задач проекта - Orchestra, Jira, Linear, GitHub Issues - через семь гейтов, и содержит справочник Orchestra MCP (модель полей, режимы отказа, рецепты запросов) как отдельный навык, независимый от этой экосистемы. Используйте, когда доска должна говорить правду о работе в процессе: выбор задачи, которую действительно можно начать, поддержание честности чек-листа во время работы, доказательство каждой строки приёмки и отчёт о том, что НЕ было сделано, наряду с тем, что было. Полная история в CHANGELOG.md.

**Стоимость**: лёгкая | **Стабильность**: стабильный | **Версия**: 3.6.0 | **Категория**: workflow

**Цели**: claude-code

**Требует**: CLI: forgeplan; MCP: orchestra

## Команды

| Команда | Что делает |
|---|---|
| `/session` | Протокол начала сессии с паттерном Inbox. |
| `/sync` | Двунаправленная синхронизация между артефактами Forgeplan и задачами Orchestra. |

## Агенты

| Агент | Что делает |
|---|---|
| `orchestra-advisor` | Фоновый советник, который предлагает действия по синхронизации задач Orchestra при использовании команд Forgeplan. |
| `task-runner` | Проводит одну отслеживаемую задачу от начала до конца в любом трекере задач проекта - Orchestra, Jira, Linear, GitHub Issues. |

## Навыки

- `orchestra-mcp` - Руководство по серверу Orchestra MCP - что на самом деле делают его инструменты и как они отказывают, когда отказывают молча.
- `task-cycle` - Этот навык следует использовать, когда пользователь спрашивает «что мне делать дальше», «возьми эту задачу», «начни работу над X», «закрой задачу», «обнови статус», «перемести в done», «что заблокировано», «что готово», «создай задачу», «добавь чек-лист», «отчитайся по задаче» или упоминает доску задач, issue, тикет, статус или чек-лист.
- `unified-workflow` - Агентный RAG-роутер для единой базы знаний рабочего процесса Forgeplan + Orchestra + Claude Code.
