Находит признаки шаблонного AI-кода — избыточные комментарии, защитные проверки без пользы, абстракции с одной реализацией, общие имена и копипасту. `/code-audit` анализирует без правок; `/code-deslop` предлагает очистку с обязательным сохранением поведения. Детерминированный сканер даёт сигнал 0–100, а не доказательство авторства, корректности или безопасности кода.

**Стоимость**: лёгкая | **Стабильность**: стабильная | **Версия**: 1.4.1 | **Категория**: качество

**Целевые платформы**: claude-code

**Требования**: Claude Code для штатных команд и агента; Python 3 для сканера (стандартная библиотека, без дополнительных пакетов). После переписывания нужен тестовый набор проекта, чтобы проверить заявление о сохранении поведения.

## Команды

| Команда | Что делает |
|---|---|
| `/code-audit` | Детекция AI-slop в исходном коде только для чтения. |
| `/code-deslop` | Переписывание с сохранением поведения, которое удаляет слой AI-slop из исходного кода - избыточные комментарии, защитную раздутость, абстракции с одной реализацией, общие имена, баннеры, эмодзи, дублирующиеся блоки - БЕЗ изменения логики, потока управления или выходных данных. |

## Агенты

| Агент | Что делает |
|---|---|
| `code-slop-cop` | Ревьюер кода, который ловит AI-slop в исходниках - машинно-сгенерированный отпечаток, из-за которого код читается как сгенерированный, а не написанный. |

## Навыки

- `code-slop` - Обнаружение и удаление AI-slop в исходном коде без изменения поведения.

Поставляются **2 файла команд, 1 агент и 1 навык**. Поддерживаются JavaScript, TypeScript, Python, Go, Rust, Java и PHP.

## Сканер и границы переписывания

`skills/code-slop/scripts/scan_code.py` считает десять эвристических метрик. Диапазоны: **>=85** — чисто, **60–84** — точечные правки, **<60** — переписывание; ниже 60 сканер возвращает ненулевой код. Его можно отдельно подключить к CI, но установка плагина этого не делает.

Метрика `single_impl_abstraction` — маловесная эвристика по объявлениям, а не полноценный поиск реализаций через AST. Оценка не заменяет code review и тесты.

`/code-deslop` сначала выполняет аудит и показывает diff, затем требует проектные тесты. Нельзя менять наблюдаемый результат, обработку ошибок, порядок вычислений или публичный API. Без тестов сохранение поведения остаётся **непроверенным**; более высокий балл сканера сам по себе его не подтверждает.

## Хуки

Собственного `hooks/hooks.json` нет. `code-slop-cop` вызывается по запросу; автоматический аудит на каждой записи или CI-гейт не включаются установкой.

## Модели и переносимость

`code-slop-cop` требует уровня **B**. `model: sonnet` — привязка Claude Code; в OMP, OpenCode, Codex и Gemini CLI сопоставьте B с моделью своей конфигурации, при сомнении — выше. Перенос инструкций не настраивает доступ к Python и проектным тестам в другом клиенте.
