Практический сборник рецептов Forgeplan. Более 25 инструкций в девяти разделах охватывают начало работы, создание PRD, доказательства, инженерный цикл, работу с несколькими плагинами, координацию агентов, устранение ошибок, справочник CLI/MCP и многоязычные монорепозитории. Формат рецепта: цель → команда → пример → типичные ошибки. Используйте, когда нужна последовательность действий, а не объяснение методологии.

**Стоимость**: лёгкая | **Стабильность**: стабильная | **Версия**: 1.2.4 | **Категория**: developer-tools

**Целевая платформа**: claude-code

**Требования**: для чтения рецептов достаточно Claude Code; для выполнения примеров нужен установленный `forgeplan`, а для MCP-примеров также настроенный сервер Forgeplan. Плагин не устанавливает CLI. Точные параметры текущего релиза сверяйте с `forgeplan <команда> --help` или схемой MCP.

## Навыки

- `fp-cookbook` - Выбирает подходящий рецепт и загружает нужную инструкцию через оглавление. Отдельных команд, агентов и регистраций хуков у версии 1.2.4 нет.

## Установка

```bash
/plugin marketplace add ForgePlan/marketplace
/plugin install fp-cookbook@ForgePlan-marketplace
```
