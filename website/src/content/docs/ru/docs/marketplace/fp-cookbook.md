Практическая кулинарная книга рецептов forgeplan CLI - ориентированные на задачи руководства, охватывающие онбординг, создание PRD, паттерны доказательств, циклы рабочего процесса, дисциплину работы с несколькими плагинами, диспетчеризацию AI-пары, устранение неполадок и краткий справочник CLI/MCP, каждый в формате цель → команда → пример → типичные ошибки. Используйте, когда вы знаете, чего хотите от forgeplan, и вам нужен точный вызов, а не методология, стоящая за ним. Полная история в CHANGELOG.md.

**Стоимость**: лёгкая | **Стабильность**: стабильная | **Версия**: 1.2.4 | **Категория**: developer-tools

**Целевые аудитории**: claude-code

**Требования**: Ничего, кроме Claude Code

## Навыки

- `fp-cookbook` - Практическая кулинарная книга рецептов forgeplan CLI - более 25 ориентированных на задачи руководств, отвечающих на вопрос "как мне сделать X?" для пользователей forgeplan CLI и Claude в качестве ассистента.

## Установка

```bash
/plugin marketplace add ForgePlan/marketplace
/plugin install fp-cookbook@ForgePlan-marketplace
```
