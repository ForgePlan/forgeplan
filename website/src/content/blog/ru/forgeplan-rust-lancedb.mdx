Forgeplan - это Rust CLI + MCP-сервер с приоритетом локальной работы (local-first), который я теперь называю **agent harness**: среда с правилами для AI-агента, который пишет код. Она задаёт, где агент может писать, какое состояние обязан читать, какие доказательства обязан готовить и какие проверки обязан пройти, прежде чем объявить задачу выполненной. Термин «harness engineering» я взял из walkinglabs ([walkinglabs.github.io/learn-harness-engineering](https://walkinglabs.github.io/learn-harness-engineering/)). Двенадцать коротких лекций помогли точнее назвать то, о чём я полгода говорил неточно.

Что отличает Forgeplan:

- **Markdown - источник истины, LanceDB - производный индекс** (ADR-003). После устранения 32 нарушений доступ ограничили через `pub(crate)`, и теперь инвариант проверяет компилятор.
- **Доверие = слабое звено.** `R_eff = min(evidence_scores)`, никогда среднее. Штраф за уровень контекстного соответствия CL (0.0/0.1/0.4/0.9) делает «прочитал в блоге» слабее, чем «измерили сами», в самой формуле. Проверка перед активацией блокирует `forgeplan activate`, если `R_eff = 0`.
- **Контракт hint-протокола** (PRD-071): каждый ответ CLI/MCP выдаёт ровно одну итоговую подсказку о следующем действии (`Next:` / `Or:` / `Fix:` / `Wait:` / `Done.`), чтобы агент никогда не придумывал порядок самостоятельно.
- **73 MCP инструмента** для Claude Code, Cursor, Aider. Локальный поиск BGE-M3 1024d.

Стек: рабочее пространство Rust из трёх крейтов, встроенная LanceDB, fastembed, rmcp. Один бинарный файл ~41 МБ с удалёнными отладочными символами (stripped). 1995 тестов.

Чего не хватает: трассировки выполняемых задач на уровне сессии (H1); артефакта «Sprint Contract» между Note и PRD (H2); жёсткого лимита WIP=1 на захваты агентов (H9). Всё это в публичном плане развития.

Репозиторий: [github.com/ForgePlan/forgeplan](https://github.com/ForgePlan/forgeplan). Установка: `brew install ForgePlan/tap/forgeplan`.
