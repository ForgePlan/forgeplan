> **Исторический снимок; уточнение от 2026-10-23.** Числа, размер бинарника, стек fastembed и дорожная карта ниже — рассказ автора за май 2026, не текущие замеры релиза или результаты приёмки. Код на обложке — схема, не исполнимый пример API. В выбранной сборке `0.39.0+constellation.s1.1` сохранённые каталоги содержат 76 MCP-инструментов полного профиля и 9 профиля чтения; публичный `0.38.0` — отдельный релиз.

Forgeplan — local-first Rust CLI + MCP-сервер, который я называю **agent harness**: структурированные артефакты, валидация и операции жизненного цикла помогают организовать чтение и доказательства агента. Они не изолируют произвольную запись файлов и не гарантируют соблюдения инструкций. Фрейминг «harness engineering» взят из walkinglabs ([курс](https://walkinglabs.github.io/learn-harness-engineering/)); это атрибуция авторской рамки, не независимая проверка Forgeplan.

Что специфично для Forgeplan:

- **Markdown - источник правды, LanceDB - производный индекс** (ADR-003, compile-enforced после очистки 32 нарушений, завершившейся локдауном через `pub(crate)`).
- **Скоринг продукта берёт слабейшее учитываемое доказательство.** CL-штрафы — 0/0.1/0.4/0.9, но соответствие контексту нужно оценивать, а не выводить из ярлыков «блог» и «наш замер». Рекурсивный скорер учитывает также verdict, тип evidence и зависимости. У активации есть гейты валидации, содержательности и связи с evidence; одного балла недостаточно для одобрения релиза.
- **Hint-протокол** (PRD-071): предусмотрены маркеры `Next:` / `Or:` / `Fix:` / `Wait:` / `Done.`. Они помогают выстроить работу, но подсказка есть не в каждом ответе и сама может содержать дефект. Агент всё равно должен проверить контракт команды и результат.
- **73 MCP инструмента** для Claude Code, Cursor, Aider. Локальный поиск BGE-M3 1024d.

Стек: Rust воркспейс из трёх крейтов, LanceDB embedded, fastembed, rmcp. Один stripped бинарник ~41 МБ. 1995 тестов.

Чего не хватает: трассировка задач runtime на уровне сессии (H1); артефакт «Sprint Contract» между Note и PRD (H2); жёсткий лимит WIP=1 на захваты агентов (H9). Всё это в публичном роадмапе.

Репозиторий: [github.com/ForgePlan/forgeplan](https://github.com/ForgePlan/forgeplan). Установка: `brew install ForgePlan/tap/forgeplan`.
