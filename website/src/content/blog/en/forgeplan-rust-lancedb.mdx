> **Historical snapshot; clarification added 2026-10-23.** Counts, binary size, fastembed stack and roadmap below are the author's May 2026 report, not current release measurements or acceptance results. The code pictured on the cover is schematic, not an executable API example. In the selected `0.39.0+constellation.s1.1` build, captured catalogs list 76 full-profile MCP tools and 9 read-profile tools; public `0.38.0` is a separate release.

Forgeplan is a local-first Rust CLI + MCP server that I describe as an **agent harness**: structured artifacts, validation and lifecycle operations help organize what an agent should read and prove. They do not sandbox arbitrary filesystem writes or guarantee that the agent obeys instructions. The "harness engineering" framing comes from walkinglabs ([course](https://walkinglabs.github.io/learn-harness-engineering/)); that attribution describes the author's framing, not independent validation of Forgeplan.

What's specific to Forgeplan:

- **Markdown is source of truth, LanceDB is a derived index** (ADR-003, compile-enforced after a 32-violation cleanup that ended with `pub(crate)` lockdown).
- **Product scoring uses the weakest eligible evidence.** CL penalties are 0/0.1/0.4/0.9, but context fit must be assessed rather than inferred from "blog" versus "our measurement." The recursive scorer also uses verdicts, evidence types and dependencies. Activation has validation, substance and evidence-link gates; a score alone is not release approval.
- **Hint protocol** (PRD-071): intended next-action markers are `Next:` / `Or:` / `Fix:` / `Wait:` / `Done.`. They help order work, but not every response carries a hint, and emitted hints can contain defects. Agents must still check the command contract and result.
- **73 MCP tools** for Claude Code, Cursor, Aider. BGE-M3 1024d local search.

Stack: Rust 3-crate workspace, LanceDB embedded, fastembed, rmcp. Single ~41 MB stripped binary. 1995 tests.

What's missing: per-session runtime task trace (H1); a "Sprint Contract" artifact between Note and PRD (H2); WIP=1 hard limit on agent claims (H9). All on the public roadmap.

Repo: [github.com/ForgePlan/forgeplan](https://github.com/ForgePlan/forgeplan). Install: `brew install ForgePlan/tap/forgeplan`.
