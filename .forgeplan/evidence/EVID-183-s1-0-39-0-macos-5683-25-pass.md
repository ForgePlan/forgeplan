5. Бинарники: forgeplan `96cd31a5…`, forgeplan-mcp `22fd8fa3…`. `forgeplan --version` печатает 0.39.0+constellation.s1.1.

Четыре оговорки v0395 закрыты исполнением:

- a) `constellation pack` теперь честен по бюджету: при `budget_tokens` меньше smallest matched unit возвращается типизированный `InsufficientBudget { budget_tokens, smallest_unit_tokens }`. При нормальном бюджете обёртка содержит `payload_bytes`, чтобы отделить стоимость наполнения от стоимости приёма.
- b) `KEY@qualifier` (`src:<hash>` / `@<segment>` / `@<suffix>`) поддержан в `constellation impact` и `constellation graph`: указанный источник идёт первым в walk, остальные не подмешиваются. Bare-ключ по-прежнему same-source only: `ADR-001` в проекте A не сливается с `ADR-001` в проекте B.
- c) Scope handle immutable: `constellation_open` запоминает `source_set_digest` каждого источника; scope-чтения (search/get/graph/impact/pack) сначала проверяют, что источники ещё отвечают теми же байтами, иначе возвращают `snapshot_expired`, а не тихо выдают новые байты.
- d) Векторы покрывают всё тело, не его префикс: длинная секция окнами по `body_prefix_chars` становится набором строк `constellation_sections_v1`. Реальный документ с 3290-символьным телом получил 4 ready rows; хвостовой токен найден со score 0.541.
- e) Бонус: `--semantic` пропускает model load, когда `count_eligible_semantic` возвращает 0 для текущего view и профиля. Без опубликованных векторов CLI отвечает за 0.01 с. Инференс остаётся per-process; постоянный daemon — отдельная задача с собственными режимами отказа, не закрывается здесь.
