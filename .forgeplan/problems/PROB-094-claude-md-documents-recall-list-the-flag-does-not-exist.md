## Problem

`CLAUDE.md` — файл, который подгружается в контекст агента **каждый ход** —
документирует команду, которой нет:

```
- **List**: `forgeplan recall --list` — show all keys
```

Флага `--list` у `recall` не существует. Агент, следующий инструкции дословно,
получает:

```
error: unexpected argument '--list' found
```

Реальная сигнатура (`forgeplan recall --help`):

```
Usage: forgeplan recall [OPTIONS] [QUERY]
Options: -c/--category, -n/--limit, --json
```

## Reproducer

```
$ forgeplan recall --list
error: unexpected argument '--list' found
```

Найдено стендом `scripts/cli-surface-exercise.sh` — это его единственный
незакрытый FAIL, оставленный падать намеренно.

## Why it matters more than a typo

Ошибка не в справке и не в сайте, а в **инструкции для агента**. Разница
существенная: человек, увидев отказ, посмотрит `--help`. Агент, которому
сказано «список ключей делается вот так», потратит ход на неработающую команду,
а в худшем случае решит, что памяти нет, и пойдёт дальше без неё.

Это тот же класс, что PROB-088 и PROB-092: инструмент ведёт себя корректно,
неверен контракт вокруг него.

## Options

**(a) Убрать строку из CLAUDE.md** и заменить рабочей формой — вероятно
`forgeplan recall` без запроса, если она возвращает всё. Требует проверки:
что именно печатает `recall` без аргументов.

**(b) Добавить флаг `--list`** — если перечисление всех ключей это отдельный
осмысленный режим, отличный от пустого запроса. Тогда документация была
опережающей, а не ошибочной.

Выбор между ними — вопрос о том, что задумывалось. Требует проверки поведения
`recall` без аргументов, а не догадки.

## Ширина проблемы не измерена

Проверена одна команда, потому что стенд споткнулся именно о неё. **Сколько
ещё команд в CLAUDE.md документированы неточно — неизвестно.** Отдельная
задача: прогнать все примеры команд из CLAUDE.md через стенд. Пока это не
сделано, честно считать, что это не единственный случай.
