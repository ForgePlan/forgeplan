# Brand assets

Эта папка содержит ассеты из текущего исходного кода сайта ForgePlan.

- `logo-dark.svg` / `logo-light.svg` — компактный контурный знак.
- `favicon*.svg`, `favicon.ico`, `icon-512.png`, `apple-touch-icon.png` — варианты wireframe cube для браузера и приложений.

Важно: в части существующих favicon-файлов всё ещё встречается исторический `#FF5A1F`. Дизайн-система фиксирует `#FF6B35` как канонический ember и описывает миграцию в `DESIGN-SYSTEM.ru.md` / `DESIGN-SYSTEM.en.md`.
