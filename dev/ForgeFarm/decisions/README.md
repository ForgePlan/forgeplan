# decisions/ — решения по ForgeFarm (pre-ADR)

Каталог для **зафиксированных решений** по ForgeFarm на стадии, пока проект
ещё не имеет собственного репозитория и `.forgeplan/` workspace.

## Правила

1. **Одно решение = один файл** `D-NNN-<kebab-slug>.md`.
2. Формат — облегчённый MADR: `Контекст → Варианты → Решение → Последствия → Что флипнет решение`.
3. Решение записывается **только после** того, как развилка из
   `../synthesis/02-open-decisions.md` реально решена (есть аргумент,
   evidence или eval-результат), а не «чтобы было».
4. Когда у ForgeFarm появится собственный репозиторий с `.forgeplan/` —
   содержимое этого каталога **мигрирует в полноценные ADR** через
   `forgeplan new adr` (RED-LINE #11: мутации артефактов только через
   MCP/CLI). Этот каталог — временный дом, не замена ForgePlan.
5. Решения, уже принятые корпусом исследований единогласно, НЕ дублировать
   сюда — они живут в `../synthesis/01-consensus.md` как инварианты.
