## Предлагаемый сценарий S-P3-446-P

- **GIVEN:** две закреплённые Git-ревизии без правок рабочего дерева, зафиксированный профиль Rust, авторизованные снимки, явная принятая связь тестового сценария и достаточный бюджет. Независимый проверяющий размечает ожидаемые пути, потребителей и пробелы до работы исполнителя.
- **WHEN:** на тех же снимках вызываем реальный публичный запрос P3 через CLI и MCP: сначала от диффа, затем от ключа сценария с тем же сравнением.
- **THEN:** обе точки входа находят одно и то же обязательство, квалифицированные символы и затронутые пути. План даёт порядок: **ограничение ADR и сценарий → дифф правила и извлечения → направление чтения связей → затронутые потребители, включая неизменённый MCP validate → проверки и пробелы**. Каждый шаг содержит действие, причину, репозиторий, ревизию и точное место. Одинаковый захват и запрос дают одинаковый порядок и идентификатор содержательного результата; переход открывает указанную версию. Необнаруженный потребитель не превращается в «никого больше нет».

| Контроль | Что должно быть видно |
|---|---|
| Есть действующая связь; рядом в таблице `FR-1`; есть только обратное ребро для другого документа. | Нет ложной тревоги по действующей связи и `FR-1`; обратное ребро не закрывает недостающее исходящее. |
| Убрать принятую связь; отдельно убрать ожидаемый факт или вернуть ошибку чтения связей. | `unresolved` для связи; конкретная причина неполноты для отсутствующего факта/ошибки. Пропуск MCP validate обнаруживает независимая разметка, даже если полный и инкрементальный индексы пропустили его одинаково. |
| Удалить символ либо добавить одноимённую замену без подтверждения преемственности; отдельно внести безопасную правку вне обязательства. | История удалённой ссылки остаётся видна, ложного перехода нет; безопасная правка не называется нарушением контракта. |
| Дифф меняет код и ослабляет сценарий или обязательные проверки; либо в бюджет не помещается обязательное ограничение. | Старое обязательство сохраняется для сравнения; новая редакция отдельным пунктом на согласование. Неполнота и продолжение видны; тест-кандидат не считается выполненным, обязательная проверка не исчезает. |

До заморозки независимый проверяющий закрепляет снимки и digest тестовых деклараций, профиль (`target`, features, версии анализатора и политики), границы обхода и ожидаемые результаты по контрольным случаям. Для этой пары Git-объектов `Cargo.lock` и `rust-toolchain.toml` одинаковы; фактическая конфигурация будущего прогона ещё не зафиксирована. Данный черновик не является независимым эталоном; проверки CLI/MCP, Cargo и эксперименты — **NOT_RUN**.
